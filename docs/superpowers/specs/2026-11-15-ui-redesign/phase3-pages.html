Phase 3 · ส่วนที่ทำต่อด้วย HTML mockup

หน้าที่ Figma ยังทำไม่เสร็จ ได้แก่ Profile (กลับมาใช้ radar) กับฉบับมือถือของ Submissions, Ranking และ Profile สีทั้งหมดดึงจาก token เดียวกับเว็บ (--accent-primary, --border-color, --text-secondary, …) จึงเปลี่ยนตาม theme เอง ลองเอาเมาส์ชี้จุดบน radar จะเห็น tooltip และแถวในรายการข้าง ๆ จะถูกไฮไลต์ไปด้วย

1 · Profile (desktop) — สว่าง / มืด

Radar: เส้นและพื้นใช้สี --accent-primary (สีหมึกของ theme: ดำในโหมดสว่าง ขาวนวลในโหมดมืด) พื้นโปร่ง 12% ส่วนเส้นกริดและเส้นแกนใช้สี --border-color ข้าง ๆ radar มีรายการ solved / total กับ % ให้อ่านตัวเลขจริงได้ และให้ screen reader อ่านได้ (radar เป็นภาพ จึงใส่ aria-hidden) หมวดที่ไม่มีโจทย์เลยจะไม่ขึ้นบน radar เหมือนโค้ดตอนนี้ ตัวย่อชื่อหมวดใช้ชุดเดิม (DP, D&C)

2 · มือถือ (390px)

ด้านบนเป็น top bar มี logo กับปุ่มค้นหา ด้านล่างเป็น tab bar ห้าช่อง Submissions: แต่ละรายการมีสองบรรทัด (ชื่อโจทย์กับเวลา / ผลตรวจ แถบ testcase และ id) ตัวกรองรวมอยู่ในปุ่ม Filters ปุ่มเดียว Ranking: แถวของเราติดอยู่เหนือ tab bar Profile: heatmap ชิดขวา สัปดาห์ล่าสุดจึงอยู่ในจอ ส่วน radar ขยายเต็มความกว้างและมีรายการตัวเลขอยู่ใต้กราฟ
