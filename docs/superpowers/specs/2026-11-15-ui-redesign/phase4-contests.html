Phase 4 · Contest pages (HTML mockup ให้อนุมัติก่อนเริ่มทำ)

หน้าที่ยังไม่เคยมี mockup ตาม §7.7 ส่วน ContestShell (แถบข้างของ contest) กับ Scoreboard มีแล้วใน navigation-de.html และ key-pages.html §3 จึงใช้ของเดิม ตัวอย่างข้อมูลสมมติเป็น contest "Mid-term practice" มี 5 ข้อ (A–E) เวลาทั้งหมดเป็นเวลาไทย

1 · Contests (รายการ)

แบ่งเป็นสามกลุ่ม Live / Upcoming / Past แต่ละแถวมีชื่อ ช่วงเวลา (mono) นับถอยหลัง (mono) n joined · n problems และปุ่มเดียวชิดขวา: Enter (อยู่ใน contest แล้ว), Join, Registered (ลงชื่อแล้ว รอเริ่ม → ไปหน้ารอ), Results (จบแล้ว) staff เห็นป้าย HIDDEN ที่ contest ที่ซ่อนอยู่ ถ้ากลุ่มไหนว่างก็ไม่แสดงกลุ่มนั้น ถ้าว่างทั้งหมดขึ้นข้อความธรรมดา "No contests yet."

2 · ก่อนเริ่ม (lobby)

หัวเรื่องมีป้าย SCHEDULED นับถอยหลังตัวใหญ่ และกล่องกติกา 4 ช่อง: ช่วงเวลา ระยะเวลา จำนวนข้อ และวิธีคิดคะแนน (IOI · รวมคะแนนดีที่สุดของแต่ละข้อ · คะแนนเท่ากันดูเวลาที่คะแนนขึ้นครั้งสุดท้ายก่อน) ด้านล่างเป็นรายชื่อคนที่ลงชื่อแล้ว ปุ่ม Join กดแล้วเปลี่ยนเป็น Registered (ปุ่มรองที่กดไม่ได้) เมื่อนับถึง 0 หน้าจะเข้า contest เองและไปที่ข้อ A

3 · กำลังแข่ง แต่ยังไม่ได้เข้าร่วม

เห็นแค่ตัวอักษรของข้อ (A–E) ชื่อข้อยังซ่อนอยู่ที่ฝั่ง server เหมือนตอนนี้ มีปุ่ม Join contest กดแล้วไปข้อ A ทันที ใช้แถบข้างหลักตามปกติ เพราะยังไม่ได้อยู่ใน contest

4 · กำลังแข่ง เข้าร่วมแล้ว (ContestShell + ตารางข้อ) — สว่าง / มืด

แถบข้างเปลี่ยนเป็นแถบของ contest (ตามที่ทำไว้ใน phase 2) /contests/:id เปิดมาเจอตารางข้อ: ตัวอักษร ชื่อ แถบ testcase ของคำตอบที่ดีที่สุด คะแนน และจำนวนครั้งที่ส่ง ตัวอักษร A, B, C… มาจากลำดับที่ admin จัด (B4: คอลัมน์ position ใหม่ใน contest_problems) ไม่ใช่ลำดับตัวอักษรของ id อีกต่อไป คะแนนรวมอยู่ล่างสุดของแถบข้าง

5 · กำลังตรวจรอบสุดท้าย (finishing)

หมดเวลาแล้วแต่ยังตรวจงานที่ส่งค้างอยู่ นาฬิกาค้างที่ 00:00:00 พร้อมข้อความ "Judging final submissions…" แถบข้างยังอยู่ แต่ปุ่ม Submit ทุกข้อปิดแล้ว

6 · จบแล้ว (recap)

ทุกคนเข้าได้ (ตอนนี้คนที่ไม่ได้เข้าร่วมจะถูกส่งออกไป) ถ้าเคยเข้าร่วมจะเห็นสรุปของตัวเอง: อันดับสุดท้าย คะแนน และผลของแต่ละข้อ ถ้าไม่ได้เข้าร่วมจะเห็นแค่ตารางข้อกับปุ่ม Scoreboard ข้อในตารางลิงก์ไปหน้าโจทย์ปกติ เพราะหลังจบโจทย์ย้ายกลับเข้าคลังโจทย์ทั่วไปแล้ว ใช้แถบข้างหลัก ไม่ใช่แถบของ contest

7 · หน้าโจทย์ใน contest หลังหมดเวลา

เหมือนหน้าโจทย์ปกติ (§7.3) แต่มีตัวอักษรนำหน้าชื่อ ถ้าหมดเวลาแล้ว แท็บ Submit ขึ้น "Contest ended — submissions closed" ทันทีตามนาฬิกา ไม่ต้องรอให้ server ปฏิเสธก่อน

8 · มือถือ (390px)

ใน contest แถบล่างเหลือสามช่อง Problems / Mine / Scoreboard และนาฬิกาอยู่บนแถบบน รายการ contest กับหน้า recap ใช้แถบล่างหลักห้าช่อง
