Phase 5 · Manage (HTML mockup ให้อนุมัติก่อนเริ่มทำ)

หน้า Manage ตาม §7.8 ที่ยังไม่เคยมี mockup ส่วนหน้า list ของ Problems มีแล้วใน key-pages.html §4 จึงใช้ของเดิม กติการ่วมทุกหน้า: หัวเรื่องมีปุ่มหลักสีดำได้ปุ่มเดียว · ตารางกดทั้งแถวเพื่อแก้ · เมนู ⋯ ท้ายแถว (คำสั่งลบอยู่ล่างสุด สีแดง) · แถบ bulk โผล่เฉพาะตอนเลือกแถว · สถานะเป็นจุด + ข้อความ กดสลับไม่ได้ แก้ 1–3 ช่อง = Dialog · สร้าง/แก้ไม่เกิน ~8 ช่อง = Drawer ขวา · ของที่มีหลายส่วน = หน้าเต็มมี URL และแท็บ

1 · Users

ตัวกรอง: ค้นหา · role (All / Students / Staff / Admins) · Locked · คอลัมน์ last active กับ solved มาจาก backend ใหม่ (B5) เลือกแถวแล้วแถบ bulk ขึ้นเหนือตาราง: Lock · Unlock · Change role · Export CSV (ลบผ่าน ⋯ เพราะต้องยืนยัน) ปุ่มหลัก Create users เปิด drawer สร้างทีละหลายคน ส่วน Add user ทีละคนอยู่ใน ⋯ ของหัวเรื่อง

2 · Users · แก้ไข (Drawer) / สร้างหลายคนเสร็จ / ลบ

แก้ไข: username, role, ล็อกการส่ง, ปุ่ม Reset password · สร้างหลายคนเสร็จ: ตาราง username/password พร้อม Download CSV + Copy และเตือนว่ารหัสจะไม่แสดงอีก · ลบ: ต้องพิมพ์ username ให้ตรง และบอกว่า submission กี่รายการจะหายไปด้วย ปุ่มเขียนว่า "Delete user" ไม่ใช่ "Confirm"

3 · Problem · หน้าแก้ไขเต็มหน้า /admin/problems/:id

แท็บ General / Statement / Testcases / Grader files (เฉพาะโจทย์ header) / Danger zone · ถ้ามี submission แล้วจะขึ้น "type locked · N submissions" ไว้ด้านบนเลย (B6) แท็บ Testcases: บรรทัดสรุป ตาราง และที่วางไฟล์ ถ้าแทนชุดทั้งหมดจะถามยืนยันพร้อมจำนวนเก่า/ใหม่ และเสนอให้ rejudge · สร้างโจทย์ใหม่ = dialog เล็กกรอก id กับ title แล้วพามาหน้านี้

4 · Contests

ตัวกรองสถานะ (All / Scheduled / Running / Finished) · สถานะเป็นจุด + เวลาที่เหลือถ้ากำลังแข่ง · คลิกแถวไปหน้าแก้ไข หน้าแก้ไข /admin/contests/:id แท็บ Settings / Problems (ลากจัดลำดับ = A, B, C… ที่นักเรียนเห็น, เพิ่มโจทย์ด้วยช่องค้นหา) / Participants (ดูอย่างเดียว) · สร้าง ใน drawer: ชื่อ คำอธิบาย วันเวลาเริ่ม ระยะเวลา (ปุ่มลัด) การมองเห็น และบอกชัดว่าเวลาเป็น Asia/Bangkok

5 · Analysis (Overview)

ช่วงเวลาอยู่ที่หัวเรื่อง · แท็บเป็น URL จริง (/admin/analysis/overview, …) · KPI 5 ช่องพร้อม ▲/▼ สีกลางๆ "vs prev. 30d" · เลิกใช้ pie ของ verdict กราฟใช้สีจาก verdict token เดียวกับทั้งเว็บ · ตารางมาตรฐานพร้อม Export CSV

6 · Settings — สว่าง / มืด

สองกลุ่ม Access (การมองเห็นเว็บ, เปิดสมัคร, เปลี่ยนรหัส) และ Data (Export, Danger zone → Replace database…) · ข้อความอธิบายอยู่ซ้าย ตัวควบคุมอยู่ขวา (มือถือก็เหมือนกัน) เปลี่ยนเป็น Private จะถามยืนยันก่อน และเตือนถ้ามี contest กำลังแข่งอยู่ · บันทึกแล้วขึ้น ✓ Saved

7 · มือถือ (390px)

ตารางกลายเป็นรายการสองบรรทัด · Settings คงรูปแบบซ้าย/ขวา · หน้าแก้ไข contest ลากจัดลำดับได้ด้วยนิ้ว
