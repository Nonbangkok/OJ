Phase 6 · Authoring (HTML mockup ให้อนุมัติก่อนเริ่มทำ)

ทำตาม §7.9 ของ spec · ภาษาบนหน้าจอยังเป็นอังกฤษ · ใช้ส่วนประกอบเดิมจาก phase 2–5 ทั้งหมด (PageHeader, DataTable, Drawer, FileDrop, ConfirmDialog, StatusDot) สิ่งที่เปลี่ยนหลัก ๆ: เอาแถบนำทางซ้ายของ draft ออก (sidebar หลักอยู่ตลอด) แล้วใช้ แท็บขั้นตอน ใต้หัวเรื่องแทน · หัวเรื่องมี สถานะการบันทึก เป็นตัว mono ("Saved · rev 14") และ ปุ่มหลักปุ่มเดียวที่เปลี่ยนตามสถานะ (Verify ตอนยังไม่ verify · Publish ตอนพร้อม · ไม่มีปุ่มระหว่างมีงานรัน) · backend ใหม่สองอย่าง: B7 ส่งความพร้อม 5 ข้อมาในรายการ draft · B8 นับ draft ที่ใช้แต่ละ author profile และค้นหา username เพื่อผูกบัญชี

1 · Authoring · รายการ draft /admin/authoring

แท็บย่อยใต้หัวเรื่อง: Drafts · Author profiles · AI docs (แทนลิงก์สองปุ่มเดิม) · ช่อง Ready เป็นสี่เหลี่ยมเล็ก 5 ช่องเรียง Statement · Solution · Testcases · PDF · Verified (เขียว = ผ่าน · เหลือง = ล้าสมัย เช่น PDF เก่ากว่า revision · เทา = ยังไม่มี) ข้อมูลมาจาก B7 · สถานะใช้ dot + คำ ไม่ใช้ badge สี · Published บอก revision ที่ live อยู่ · กดทั้งแถวเพื่อเปิด draft · ⋯ มี Open, Start new revision (เฉพาะที่ publish แล้ว), Delete

2 · Author profiles + แก้ไขใน Drawer

เปลี่ยนจากการ์ดเป็นตาราง: รูป + AKA · ชื่อจริง · ภาษา · ประเทศ · บัญชีที่ผูก · จำนวน draft ที่ใช้ (B8) · ⋯ · แก้ไขใน Drawer ขวา (ตัด/ซูมรูปอยู่ใน Drawer) · ผูกบัญชีด้วยการค้นหา username แทนการพิมพ์เลข user id (B8) · ถ้าแก้ชื่อ/ภาษา/ประเทศของ profile ที่มี draft ใช้อยู่ ปุ่ม Save จะถามก่อนว่าจะ sync draft ที่ผูกไว้กี่อัน (dialog เดิม "Update linked problems?") · ประวัติ sync ย้ายมาอยู่หน้านี้

3 · Draft workspace · Metadata /admin/authoring/:id

หัวเรื่อง: breadcrumb · ชื่อโจทย์ + สถานะ · บรรทัด meta = problem id และ สถานะการบันทึก (Saved · rev 14 / Saving… / Unsaved) · ปุ่มหลัก Verify · แท็บขั้นตอนมีเครื่องหมายบอกสถานะ: ✓ เสร็จ · ○ ยังไม่ทำ · ◐ ล้าสมัย · ✕ ล้มเหลว คำนวณจากข้อมูลที่โหลดอยู่แล้ว · History กับ AI docs เป็นลิงก์ชิดขวา ไม่ใช่ขั้นตอน · ฟอร์มสองคอลัมน์ ช่องตัวเลขมีหน่วย error อยู่ใต้ช่อง หมวดหมู่เป็นชิปกดเลือก

4 · Statement

แสดงโจทย์ที่ render แล้วแบบอ่านอย่างเดียว + ปุ่ม Edit statement (เปิดตัวแก้เต็มจอ) · PDF เป็นแถวเดียว บอก revision และถ้าเก่ากว่า draft จะขึ้นสีเหลือง พร้อม Rebuild / Open · รูปประกอบเป็น FileDrop + ตาราง (คัดลอก path ไปใส่ในโจทย์ได้)

5 · ตัวแก้โจทย์เต็มจอ (FocusShell)

ไม่มี sidebar · ด้านบน: ← กลับ workspace · ชื่อ · สถานะการบันทึกเห็นตลอด · ถ้าโจทย์ publish แล้วจะมีป้ายแยก "Published · live unchanged" (แก้ได้ แต่โจทย์ที่ live ยังไม่เปลี่ยนจนกว่าจะ publish ใหม่) · Preview / PDF สลับได้ · preview ขยายพอดีความกว้างเป็นค่าเริ่มต้น · ตัวแก้มีเลขบรรทัดและสีไวยากรณ์ (ตัวเดียวกับหน้าส่งโค้ด) · มือถือแยกเป็นแท็บ Source / Preview

6 · Solution (Generator หน้าตาเดียวกัน) · ระหว่างมีงานรัน

ตัวแก้โค้ด + แผงผลการ compile ล่าสุด ที่ revision นี้ · ตัวอย่างนี้คือ ระหว่างงานรัน: หัวเรื่องมี pill "Compile solution · running" และไม่มีปุ่มหลัก ตัวแก้เป็นอ่านอย่างเดียวชั่วคราว · "Generate inputs" อยู่ที่แท็บ Generator · ตัวแก้เปลี่ยนสีตาม theme

7 · Testcases

บรรทัดสรุป (จำนวน · ขนาดรวม · ขาด output กี่ไฟล์) · แถว Generate (seed + Generate inputs / Generate outputs) · ตารางกะทัดรัด ช่อง Source บอกว่ามาจาก upload หรือ generate ที่ rev ไหน · ⋯ ต่อแถว: Inspect · Replace · Delete · วางไฟล์คู่ทีละเคสได้ หรือ Replace all from ZIP (ถามยืนยันพร้อมจำนวนเก่า/ใหม่) · มือถือดูได้อย่างเดียว

8 · Verify & publish — สว่าง / มืด

ReadinessList หนึ่งแถวต่อเงื่อนไข: Metadata · Statement · Solution compiles at rev N · Testcases · PDF current · Verified rev N พร้อมสถานะและลิงก์แก้ไปยังแท็บที่เกี่ยว · แท็บนี้ไม่มีปุ่มหลักบนหัวเรื่อง ปุ่มอยู่ท้ายรายการแทน: Verify (รอง) · Publish (หลัก) ถ้ายัง publish ไม่ได้ ปุ่มจาง และบอกเหตุผลข้างปุ่ม · ถ้า verify ล้มเหลวจะแสดงเคสที่พังและคำอธิบายจาก error code เดิม

9 · History

ตาราง timeline ของงาน build (งาน · สถานะ · revision · เวลา) กดแถวแล้ว log เปิดใน Drawer · แก้ชื่องานที่เคยโชว์ไม่ตรง (run_generator → "Generate inputs") และสถานะที่ยังไม่มีชื่อ (Timed out / Cancelled / Stale) · ประวัติ sync ของ author profile ย้ายไปหน้า Author profiles

10 · มือถือ (390px)

รายการและหน้าดูทุกหน้าใช้ได้ · แก้ได้แค่ Metadata · ตัวแก้โค้ด/โจทย์และการอัปโหลดจะขึ้น "Best edited on a larger screen" · แท็บขั้นตอนเลื่อนแนวนอนได้
