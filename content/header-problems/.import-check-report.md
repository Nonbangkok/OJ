## Findings
- `processBatchUpload` DELETES the ZIP it is given (the first run, on a read-only mount, warned EROFS). The test therefore imports a temp copy. Anyone importing by script must not point it at dist/.
- The reference solution is not in dist/ (dist has only grader/starter/testcases/pdf/config); the test reads `problems/<id>/solution.h` (HEADER_PROBLEMS_SRC). Judge case is skipped for ids without one.
- The test is generic: it covers every id found in dist/, so the other 49 are checked automatically on rebuild. Mind the per-test 120 s timeout if many problems are judged in one run.
