# Pair Equal

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวที่อาจเป็นชนิดต่างกัน
ไว้ในตัวแปรสมาชิก <b>`T1 first`</b> และ <b>`T2 second`</b> คลาสนี้มี
คอนสตรักเตอร์สองตัว คือตัวที่ไม่รับพารามิเตอร์ (ให้สมาชิกทั้งสองเป็นค่าเริ่มต้น
ของชนิดนั้น) และตัวที่รับค่าของสมาชิกทั้งสองมาตรง ๆ

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
bool CP::pair<T1, T2>::operator==(const CP::pair<T1, T2> &other) const;
```

ที่คืนค่า `true` เมื่อคู่อันดับทั้งสองมีค่าเท่ากัน และคืน `false` เมื่อไม่เท่ากัน
คู่อันดับสองคู่นับว่า <b>เท่ากันเมื่อสมาชิกทั้งสองตัวเท่ากัน</b> นั่นคือ `first`
ของคู่หนึ่งเท่ากับ `first` ของอีกคู่ และ `second` ของคู่หนึ่งเท่ากับ `second`
ของอีกคู่ ถ้าตำแหน่งใดตำแหน่งหนึ่งต่างกัน คู่อันดับทั้งสองก็ไม่เท่ากัน

ชนิด `T1` และ `T2` รับประกันว่ามีตัวดำเนินการ `==` ของตัวเองอยู่แล้ว คุณจึง
เปรียบเทียบสมาชิกแต่ละตัวได้โดยตรง และต้องเขียนให้ใช้ได้กับทุกชนิดที่ส่งเข้ามา
ไม่ใช่เฉพาะ `int`

คลาสนี้ยังมีตัวดำเนินการ `!=` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยนิยามจาก
`==` ของคุณ ดังนั้นถ้า `==` ผิด `!=` ก็จะผิดตามไปด้วย และในไฟล์
`{{submission}}` ยังมีฟังก์ชัน `set` ที่กำหนดค่าสมาชิกทั้งสองพร้อมกัน ซึ่ง
เขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมายเดิมไว้

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ $n$ แล้วอ่านคู่อันดับชนิด
`CP::pair<int,int>` มา $n$ คู่ คู่แรกจะถูกเก็บไว้เป็นคู่อ้างอิงด้วยฟังก์ชัน
`set` จากนั้นสำหรับทุกคู่ที่อ่านเข้ามา โปรแกรมจะพิมพ์ผลของ `==` และ `!=`
เทียบกับคู่อ้างอิง เป็น `1` หรือ `0` ในหนึ่งบรรทัด

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> แล้วเรียก `==`, `!=`, `set`, คอนสตรักเตอร์ และการคัดลอก
  คู่อันดับสลับกันไปมา ไม่ใช่เรียกตามรูปแบบเดียวกับ `main.cpp` ข้างต้น
* สร้างคู่อันดับจากชนิดข้อมูลมากกว่าหนึ่งแบบ คือ `CP::pair<int,int>` และ
  `CP::pair<std::string,int>`
* พิมพ์ผลของ `==` และ `!=` คู่กันทุกครั้ง ถ้าทั้งสองไม่ขัดแย้งกันเสมอ จะต้อง
  ได้ผลเป็น `1 0` หรือ `0 1` เท่านั้น

ดังนั้นถ้าคุณแก้ `set` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป ระบบจะจับได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนคู่อันดับ<br>
$n$ บรรทัดถัดมา : บรรทัดที่ $i$ $(1 \leq i \leq n)$ รับจำนวนเต็ม $a_i$ และ
$b_i$ แทนสมาชิก `first` และ `second` ของคู่อันดับที่ $i$ โดยคู่อันดับที่ $1$
เป็นคู่อ้างอิง

## Output :

มีทั้งหมด $n$ บรรทัด โดย<br>
บรรทัดที่ $i$ $(1 \leq i \leq n)$ แสดงจำนวนเต็มสองจำนวน คือผลของ `==` และผล
ของ `!=` ระหว่างคู่อันดับที่ $i$ กับคู่อ้างอิง โดย `1` แทนจริงและ `0` แทนเท็จ

## Examples :

### ตัวอย่างที่ 1

```sample-input
3
1 2
1 2
2 1
```

```sample-output
1 0
1 0
0 1
```

## คำอธิบายตัวอย่างที่ 1

คู่แรก $(1, 2)$ เป็นคู่อ้างอิง คู่ที่สองเท่ากันทุกตำแหน่งจึงได้ `1 0` คู่ที่สาม
สลับค่ากัน ทั้ง `first` และ `second` ต่างกัน จึงได้ `0 1`

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ $n$ ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `cmp i j` | พิมพ์ผลของ `A[i] == A[j]` และ `A[i] != A[j]` |
| `set i a b` | เรียก `A[i].set(a, b)` |
| `assign i j` | ทำ `A[i] = A[j]` แล้วพิมพ์ผลของ `A[i] == A[j]` |
| `copy i` | สร้างสำเนาด้วย copy constructor แล้วพิมพ์ผลเทียบกับ `A[i]` |
| `temp i a b` | สร้างคู่อันดับชั่วคราวจาก $(a, b)$ แล้วพิมพ์ผลเทียบกับ `A[i]` |
| `zero i` | พิมพ์ผลของ `A[i]` เทียบกับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะวนเทียบคู่อันดับที่อยู่ติดกันทั้งอาเรย์
แล้วพิมพ์ผลรวมจำนวนคู่ที่เท่ากัน จึงเป็นการตรวจทั้งอาเรย์ ไม่ใช่แค่ตำแหน่งที่
ถูกถามถึง

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีคู่อันดับ $n \leq 20{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 60{,}000$ คำสั่ง
* สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน $10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
