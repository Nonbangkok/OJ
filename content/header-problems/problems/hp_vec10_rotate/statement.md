# Vector Rotate

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บสมาชิก `mSize` ตัวเรียงติดกันใน
`mData[0]` ถึง `mData[mSize - 1]` ของอาเรย์ที่จองไว้ `mCap` ช่อง การหมุน
สมาชิกทั้งเวกเตอร์เป็นงานที่ดูเหมือนต้องใช้ที่พักข้อมูลเพิ่ม แต่โจทย์นี้จำกัด
หน่วยความจำไว้ต่ำโดยตั้งใจ เพื่อให้ต้องหาวิธีที่ทำได้ในที่เดิม

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::rotate(size_t k);
```

ที่หมุนสมาชิกทั้งเวกเตอร์ไปทางซ้าย $k$ ช่อง นั่นคือสมาชิกที่เคยอยู่ตำแหน่ง
$k$ ต้องมาอยู่ตำแหน่ง $0$ สมาชิกที่เคยอยู่ตำแหน่ง $k + 1$ มาอยู่ตำแหน่ง $1$ และ
สมาชิกที่ล้นออกทางซ้ายให้วนไปต่อท้าย พูดให้ตรงคือ สมาชิกตำแหน่ง $i$ ใหม่
เท่ากับสมาชิกตำแหน่ง $(i + k) \bmod n$ เดิม เมื่อ $n$ คือ `size()`

ข้อกำหนด

1. $k$ อาจ <b>มากกว่า $n$</b> ได้ (และอาจเป็น $0$) การหมุนด้วย $k$ ที่เป็น
   พหุคูณของ $n$ ต้องได้เวกเตอร์เดิม ให้ลดค่าด้วย $k \bmod n$ ก่อน
2. เวกเตอร์ว่างหรือมีสมาชิกตัวเดียวต้องไม่เปลี่ยนแปลง (และห้ามหาเศษด้วย $0$)
3. `size()` และ `capacity()` ต้องไม่เปลี่ยน
4. <b>ต้องใช้เวลา $O(n)$</b> ต่อการหมุนหนึ่งครั้ง การหมุนทีละหนึ่งช่องซ้ำ $k$
   ครั้งให้คำตอบถูกต้อง แต่ใช้เวลา $O(k \times n)$ ซึ่งไม่ทันเมื่อ $n$ เป็น
   สองล้านและ $k$ เป็นหลักแสน
5. <b>ต้องใช้หน่วยความจำเพิ่มแบบคงที่ $O(1)$</b> ห้ามจองอาเรย์ชั่วคราวขนาดตาม
   จำนวนข้อมูล ข้อนี้ถูกบังคับด้วย <b>ขอบเขตหน่วยความจำ $32$ MB</b> ของโจทย์:
   ชุดทดสอบใหญ่มีสมาชิกชนิด `long long` สองล้านตัว ซึ่งคือข้อมูล
   $2 \times 10^6 \times 8 = 16$ MB โปรแกรมที่คัดลอกข้อมูลไปไว้ในอาเรย์ชั่วคราว
   ต้องใช้อีก $16$ MB รวมเป็น $16 + 16 = 32$ MB ซึ่งเกินขอบเขตเมื่อรวมกับ
   ส่วนอื่นของโปรแกรม แม้คำตอบจะถูกและเร็ว ผลที่ได้คือ `new` ล้มเหลวและโยน
   `std::bad_alloc` ซึ่งไม่มีใครรับ โปรแกรมจึงถูกยุติกลางทาง และชุดทดสอบนั้น
   ไม่ผ่าน

แนวคิดที่ใช้ได้มีหลายแบบ ที่เขียนง่ายที่สุดคือ <b>การกลับลำดับสามครั้ง</b> คือ
กลับลำดับช่วง `[0, k)` แล้วกลับลำดับช่วง `[k, n)` แล้วกลับลำดับทั้งเวกเตอร์
ลองดูกับ $1, 2, 3, 4, 5$ เมื่อ $k = 2$

```text
1 2 3 4 5   ->   2 1 3 4 5   ->   2 1 5 4 3   ->   3 4 5 1 2
```

การกลับลำดับแต่ละครั้งทำได้ด้วยการสลับสมาชิกเป็นคู่ ๆ ในที่เดิม ใช้ตัวแปร
ชั่วคราวเพียงตัวเดียว ทั้งสามรอบรวมกันจึงเป็น $O(n)$ และใช้ที่เพิ่มคงที่ (อีก
วิธีที่ใช้ได้คือการเดินตามวงจรของการสับเปลี่ยน ซึ่งขยับสมาชิกแต่ละตัวเพียง
ครั้งเดียว แต่ต้องระวังเรื่องจำนวนวงจรที่เท่ากับ $\gcd(n, k)$)

ตามข้อบังคับข้อ 2 คุณเขียนโค้ดได้เฉพาะภายในฟังก์ชัน `rotate` ใน
`{{submission}}` ดังนั้นถ้าใช้วิธีกลับลำดับสามครั้ง ให้เขียนลูปกลับลำดับสามรอบ
ไว้ในฟังก์ชันนั้นเลย

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่าน $n$ กับ $k$ แล้วอ่านสมาชิก $n$ ตัวลงใน
`CP::vector<int>` เรียก `v.rotate(k)` หนึ่งครั้ง แล้วพิมพ์ `size()` ตามด้วย
สมาชิกทั้งหมดตามลำดับใหม่

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `rotate` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์ ไม่ใช่เรียกครั้งเดียวตอนท้าย
* สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<long long>`,
  `CP::vector<int>` และ `CP::vector<std::string>`
* ใช้ค่า $k$ หลายแบบ: $0$, $1$, $n - 1$, $n$ พอดี, $n + 1$, พหุคูณของ $n$
  และค่าที่สุ่มได้ถึงสองเท่าของ $n$
* สร้างข้อมูลขึ้นเองภายในโปรแกรมจากค่า seed ดังนั้นคำสั่งบรรทัดเดียวสร้าง
  สมาชิกได้ถึงสองล้านตัว และ <b>ตัวโปรแกรมตรวจเองประหยัดหน่วยความจำอย่าง
  ตั้งใจ</b> (ชุดทดสอบใหญ่ไม่มีคำสั่งคัดลอกเวกเตอร์เลย) เพื่อให้ขอบเขต $32$ MB
  ที่เหลือเป็นของโปรแกรมคุณ
* คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การหมุนเกินหรือขาดไปหนึ่งช่อง รวมถึง
  การทำข้อมูลหายหนึ่งตัวระหว่างย้าย จึงหลบไม่ได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ และ $k$ แทนจำนวนสมาชิกและจำนวนช่องที่หมุนไป
ทางซ้าย<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ แทนสมาชิก
ของเวกเตอร์

## Output :

มีทั้งหมด $2$ บรรทัด โดย<br>
บรรทัดแรก : แสดง `size()`<br>
บรรทัดที่สอง : แสดงสมาชิกทั้งหมดตามลำดับใหม่หลังเรียก `v.rotate(k)`

## Examples :

### ตัวอย่างที่ 1

```sample-input
7 10
10 20 30 40 50 60 70
```

```sample-output
7
40 50 60 70 10 20 30
```

## คำอธิบายตัวอย่างที่ 1

ที่นี่ $k = 10$ มากกว่า $n = 7$ แต่การหมุน $7$ ช่องได้เวกเตอร์เดิม จึงเหลือ
การหมุนจริงเพียง $10 \bmod 7 = 3$ ช่อง สมาชิกตำแหน่ง $3$ ซึ่งคือ $40$ จึงมาอยู่
ตำแหน่ง $0$ และ $10, 20, 30$ วนไปต่อท้าย

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` |
| `2 k` | เรียก `rotate(k)` แล้วพิมพ์ขนาด |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4` | เรียก `rotate(size())` ซึ่งต้องไม่เปลี่ยนอะไร |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วหมุนสำเนาด้วย `k` หลายแบบ โดยต้นฉบับต้องไม่เปลี่ยน (ใช้เฉพาะชุดทดสอบเล็ก) |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10 count seed` | หมุนซ้ำ `count` ครั้งด้วยค่า `k` ที่สร้างจาก `seed` (มักมากกว่า `size()`) |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน ส่วนค่า `k`
<b>ไม่ถูกปรับ</b> เพราะการจัดการ `k` ที่ใหญ่กว่า `size()` เป็นส่วนหนึ่งของสิ่ง
ที่ตรวจ เมื่อจบบล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* บล็อกที่ใหญ่ที่สุดมีสมาชิกชนิด `long long` $2{,}000{,}000$ ตัว (ข้อมูล
  $16$ MB)
* ค่า $k$ ไม่เกินประมาณ $4n$
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^6$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $2 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $5$ ตัว
