## คำอธิบาย

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::rotate(size_t k);
```

ที่หมุนสมาชิกทั้งเวกเตอร์ไปทางซ้าย `k` ช่อง นั่นคือสมาชิกที่เคยอยู่ตำแหน่ง
`k` ต้องมาอยู่ตำแหน่ง 0 สมาชิกที่เคยอยู่ตำแหน่ง `k + 1` มาอยู่ตำแหน่ง 1 และ
สมาชิกที่ล้นออกทางซ้ายให้วนไปต่อท้าย พูดให้ตรงคือ สมาชิกตำแหน่ง `i` ใหม่
เท่ากับสมาชิกตำแหน่ง `(i + k) mod n` เดิม เมื่อ `n` คือ `size()`

ข้อกำหนด

1. `k` อาจ **มากกว่า `size()`** ได้ (และอาจเป็น 0) การหมุนด้วย `k` ที่เป็น
   พหุคูณของ `n` ต้องได้เวกเตอร์เดิม ให้ลดค่าด้วย `k % n` ก่อน
2. เวกเตอร์ว่างหรือมีสมาชิกตัวเดียวต้องไม่เปลี่ยนแปลง (และห้ามหาเศษด้วย 0)
3. `size()` และ `capacity()` ต้องไม่เปลี่ยน
4. **ต้องใช้เวลา O(n)** ต่อการหมุนหนึ่งครั้ง การหมุนทีละหนึ่งช่องซ้ำ `k`
   ครั้งให้คำตอบถูกต้อง แต่ใช้เวลา O(k × n) ซึ่งไม่ทันเมื่อ `n` เป็นสองล้าน
   และ `k` เป็นหลักแสน
5. **ต้องใช้หน่วยความจำเพิ่มแบบคงที่ O(1)** ห้ามจองอาเรย์ชั่วคราวขนาดตาม
   จำนวนข้อมูล ข้อนี้ถูกบังคับด้วย **ขอบเขตหน่วยความจำ 32 MB** ของโจทย์:
   ชุดทดสอบใหญ่มีสมาชิกชนิด `long long` สองล้านตัว ซึ่งคือข้อมูล 16 MB
   โปรแกรมที่คัดลอกข้อมูลไปไว้ในอาเรย์ชั่วคราวต้องใช้อีก 16 MB จึงเกินขอบเขต
   แม้คำตอบจะถูกและเร็ว ผลที่ได้คือ `new` ล้มเหลวและโยน `std::bad_alloc` ซึ่ง
   ไม่มีใครรับ โปรแกรมจึงถูกยุติกลางทาง และชุดทดสอบนั้นไม่ผ่าน

แนวคิดที่ใช้ได้มีหลายแบบ ที่เขียนง่ายที่สุดคือ **การกลับลำดับสามครั้ง** คือ
กลับลำดับช่วง `[0, k)` แล้วกลับลำดับช่วง `[k, n)` แล้วกลับลำดับทั้งเวกเตอร์
ลองดูกับ `1 2 3 4 5` เมื่อ `k = 2`

```
1 2 3 4 5   ->   2 1 3 4 5   ->   2 1 5 4 3   ->   3 4 5 1 2
```

การกลับลำดับแต่ละครั้งทำได้ด้วยการสลับสมาชิกเป็นคู่ ๆ ในที่เดิม ใช้ตัวแปร
ชั่วคราวเพียงตัวเดียว ทั้งสามรอบรวมกันจึงเป็น O(n) และใช้ที่เพิ่มคงที่ (อีก
วิธีที่ใช้ได้คือการเดินตามวงจรของการสับเปลี่ยน ซึ่งขยับสมาชิกแต่ละตัวเพียง
ครั้งเดียว แต่ต้องระวังเรื่องจำนวนวงจรที่เท่ากับ gcd(n, k))

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่าน `n` กับ `k` แล้วอ่านสมาชิก `n` ตัวลงใน
`CP::vector<int>` เรียก `v.rotate(k)` หนึ่งครั้ง แล้วพิมพ์

1. บรรทัดแรก: `size()`
2. บรรทัดที่สอง: สมาชิกทั้งหมดตามลำดับใหม่

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `rotate` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์ ไม่ใช่เรียกครั้งเดียวตอนท้าย
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<long long>`,
  `CP::vector<int>` และ `CP::vector<std::string>`
- ใช้ค่า `k` หลายแบบ: 0, 1, `size() - 1`, `size()` พอดี, `size() + 1`,
  พหุคูณของ `size()` และค่าที่สุ่มได้ถึงสองเท่าของ `size()`
- สร้างข้อมูลขึ้นเองภายในโปรแกรมจากค่า seed ดังนั้นคำสั่งบรรทัดเดียวสร้าง
  สมาชิกได้ถึงสองล้านตัว และ **ตัวโปรแกรมตรวจเองประหยัดหน่วยความจำอย่าง
  ตั้งใจ** (ชุดทดสอบใหญ่ไม่มีคำสั่งคัดลอกเวกเตอร์เลย) เพื่อให้ขอบเขต 32 MB
  ที่เหลือเป็นของโปรแกรมคุณ
- คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การหมุนเกินหรือขาดไปหนึ่งช่อง รวมถึง
  การทำข้อมูลหายหนึ่งตัวระหว่างย้าย จึงหลบไม่ได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
7 10
10 20 30 40 50 60 70
```

### ข้อมูลออก

```sample-output
7
40 50 60 70 10 20 30
```

ที่นี่ `k = 10` มากกว่า `n = 7` แต่การหมุน 7 ช่องได้เวกเตอร์เดิม จึงเหลือ
การหมุนจริงเพียง `10 mod 7 = 3` ช่อง สมาชิกตำแหน่ง 3 ซึ่งคือ `40` จึงมาอยู่
ตำแหน่ง 0 และ `10 20 30` วนไปต่อท้าย

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` |
| `2 k` | เรียก `rotate(k)` แล้วพิมพ์ขนาด |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4` | เรียก `rotate(size())` ซึ่งต้องไม่เปลี่ยนอะไร |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วหมุนสำเนาด้วย `k` หลายแบบ โดยต้นฉบับต้องไม่เปลี่ยน (ใช้เฉพาะชุดทดสอบเล็ก) |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10 count seed` | หมุนซ้ำ `count` ครั้งด้วยค่า `k` ที่สร้างจาก `seed` (มักมากกว่า `size()`) |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน ส่วนค่า `k`
**ไม่ถูกปรับ** เพราะการจัดการ `k` ที่ใหญ่กว่า `size()` เป็นส่วนหนึ่งของสิ่ง
ที่ตรวจ เมื่อจบบล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก บล็อกที่ใหญ่ที่สุดมีสมาชิก
ชนิด `long long` 2,000,000 ตัว (ข้อมูล 16 MB) ค่า `k` ไม่เกินประมาณ
`4 × size()` สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน 10⁶ ชนิด `long long` ไม่
เกิน 2 × 10⁹ และชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 5 ตัว
