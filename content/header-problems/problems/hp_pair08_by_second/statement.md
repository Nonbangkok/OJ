## คำอธิบาย

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
`T1 first` และ `T2 second`

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
bool CP::pair<T1, T2>::less_by_second(const CP::pair<T1, T2> &other) const;
```

ที่ใช้เป็น **ตัวเปรียบเทียบ** สำหรับการเรียงลำดับ โดย เรียงด้วยสมาชิกตัวที่สอง
ก่อน ถ้าเท่ากันจึงใช้สมาชิกตัวแรกตัดสิน นั่นคือต้องคืน `true` เมื่อ

- `second` ของ `*this` น้อยกว่า `second` ของ `other` หรือ
- `second` ของทั้งสองคู่เท่ากัน และ `first` ของ `*this` น้อยกว่า `first` ของ
  `other`

และคืน `false` ในกรณีอื่น โดยเฉพาะต้องคืน `false` เมื่อคู่อันดับทั้งสองเท่ากัน
ทุกตำแหน่ง เพราะไม่มีคู่ใดมาก่อนอีกคู่ สมบัติข้อนี้เรียกว่าเป็นความสัมพันธ์แบบ
**เข้ม** (strict) และเป็นสิ่งที่อัลกอริทึมเรียงลำดับทุกตัวต้องการ

คลาสนี้มีฟังก์ชัน `equal_by_second` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` และ
นิยามว่าสองคู่เท่ากันเมื่อไม่มีฝ่ายใดมาก่อนอีกฝ่าย ถ้า `less_by_second` ของคุณ
คืน `true` สำหรับคู่ที่เท่ากัน ฟังก์ชันนี้จะตอบผิดทันที

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `greater_by_second` ที่ตอบว่าคู่อันดับนี้
มาหลังอีกคู่หรือไม่ โดยเรียก `less_by_second` ด้วยลำดับตัวตั้งที่สลับกัน ซึ่ง
เขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมายเดิมไว้

ชนิด `T1` และ `T2` รับประกันว่ามีตัวดำเนินการ `<` ของตัวเองอยู่แล้ว

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ `n` แล้วอ่านคู่อันดับชนิด
`CP::pair<std::string,int>` มา `n` คู่ จากนั้น

1. สำหรับคู่ที่สองเป็นต้นไป พิมพ์ผลของ `less_by_second` ทั้งสองทิศทางระหว่าง
   คู่นั้นกับคู่แรก
2. เรียงคู่อันดับทั้งหมดด้วย insertion sort ที่ใช้ `less_by_second` เป็นตัว
   เปรียบเทียบ แล้วพิมพ์ผลเรียงออกมาทีละบรรทัด

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน ชุดคำสั่ง แล้วเรียก `less_by_second`, `greater_by_second`,
  `equal_by_second`, คอนสตรักเตอร์ และการคัดลอกคู่อันดับสลับกันไปมา
- สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<std::string,int>`,
  `CP::pair<int,long long>` และ `CP::pair<std::string,std::string>`
- นำ `less_by_second` ไปใช้เป็นตัวเปรียบเทียบของ **merge sort แบบ stable**
  ทั้งกับช่วงสั้น ๆ ระหว่างทาง และกับอาเรย์ทั้งชุดเมื่อจบบล็อก ลำดับที่ได้จึง
  ขึ้นกับตัวเปรียบเทียบของคุณทุกตำแหน่ง
- พิมพ์ผลเปรียบเทียบทั้งสองทิศทางคู่กันทุกครั้ง คู่ที่เท่ากันจึงต้องได้ `0 0`

ดังนั้นถ้าคุณแก้ `greater_by_second` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
3
pear 5
apple 5
fig 2
```

### ข้อมูลออก

```sample-output
1 0
1 0
fig 2
apple 5
pear 5
```

สองบรรทัดแรกคือการเทียบคู่ที่สองและคู่ที่สามกับคู่แรก `("pear", 5)` คู่
`("apple", 5)` มี `second` เท่ากันจึงตัดสินด้วย `first` และ `"apple"` มาก่อน
`"pear"` คู่ `("fig", 2)` มี `second` น้อยกว่าจึงมาก่อนทันที สามบรรทัดสุดท้าย
คือผลเรียงลำดับ ซึ่งเรียงตาม `second` เป็นหลัก

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ `n` ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `cmp i j` | พิมพ์ผลของ `less_by_second` ทั้งสองทิศทาง และ `equal_by_second` |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` ด้วยการคัดลอก |
| `sort l len` | เรียงสำเนาของช่วง `len` ตัวที่เริ่มจากตำแหน่ง `l` แล้วพิมพ์ผลเรียง |
| `gt i j` | พิมพ์ผลของ `greater_by_second` ทั้งสองทิศทาง |
| `zero i` | เทียบ `A[i]` กับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |
| `viacopy i j` | เทียบ `A[i]` กับสำเนาของ `A[j]` ที่สร้างด้วย copy constructor |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะเรียงอาเรย์ทั้งชุดด้วย merge sort แบบ
stable ที่ใช้ `less_by_second` แล้วพิมพ์จำนวนตัว ค่าตรวจสอบ (hash) ของผลเรียง
ทั้งหมด และตัวแรกกับตัวสุดท้ายของผลเรียง การเรียงแบบ stable ทำให้คู่ที่เท่ากัน
คงลำดับเดิมไว้ ผลที่ถูกต้องจึงมีเพียงแบบเดียว

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมี `n ≤ 20,000` และ
มีคำสั่งไม่เกิน `q ≤ 30,000` คำสั่ง ความยาวของช่วงในคำสั่ง `sort` ไม่เกิน 32
สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน `10^9` สมาชิกชนิด `long long` มีค่า
สัมบูรณ์ไม่เกิน `4 × 10^9` และสมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็ก
ยาวไม่เกิน 6 ตัว
