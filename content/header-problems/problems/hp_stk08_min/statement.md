# Stack Min

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก และสมาชิกตัวบนสุดของสแตกอยู่ที่
`mData[mSize - 1]` คลาสนี้ยังมีตัวแปรสมาชิก <b>`int aux`</b> ซึ่งยังไม่มีฟังก์ชัน
ใดใช้งาน และเป็นหัวใจของข้อนี้

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
const T &CP::stack<T>::min() const;
```

ที่ <b>คืนค่าสมาชิกที่น้อยที่สุดในสแตก</b> (เทียบด้วยตัวดำเนินการ `<` ของชนิด
`T`) โดยใช้เวลา <b>$O(1)$</b> ต่อการเรียกหนึ่งครั้ง ห้ามไล่ดูสมาชิกทุกตัว เพราะ
ข้อมูลชุดใหญ่ถาม `min()` มากกว่าแสนครั้งบนสแตกที่มีสมาชิกหลายหมื่นตัว

แนวคิดคือ <b>เก็บข้อมูลสรุปไว้ล่วงหน้า</b> ใน `aux` แล้วให้ `push` และ `pop`
ดูแลให้ข้อมูลนั้นถูกต้องอยู่เสมอ โจทย์จึงย้าย `top`, `push` และ `pop` มาไว้
ใน `{{submission}}` ให้คุณแก้ได้

ข้อควรคิด

* `aux` เป็น `int` ไม่ใช่ `T` จึงเก็บ <b>ค่า</b> ที่น้อยที่สุดไม่ได้ (ข้อมูล
  ทดสอบมีทั้ง `int`, `long long` และ `std::string`) แต่เก็บ <b>ตำแหน่ง</b> ได้
* `pop` ที่นำสมาชิกตัวที่น้อยที่สุดออกไป ต้องทำให้ `min()` กลับไปคืนค่าที่
  น้อยที่สุดของสมาชิกที่เหลือ ไม่ใช่จำค่าที่เคยเล็กที่สุดไว้ตลอดกาล ข้อมูล
  ทดสอบชุดเล็กจะ `push` ค่าที่ลดลงเรื่อย ๆ แล้ว `pop` ออกทีละตัว พร้อมถาม
  `min()` ทุกครั้ง
* ข้อนี้ยอมให้ `pop` <b>ที่นำตัวน้อยที่สุดออก</b> ใช้เวลา $O(\text{size}())$ เพื่อหา
  ตัวน้อยที่สุดใหม่ได้ (ข้อมูลทดสอบชุดใหญ่ออกแบบให้เหตุการณ์นี้เกิดน้อย
  ครั้ง) แต่ `min()` เองต้องเป็น $O(1)$ ทุกครั้ง และ `push` ต้องเป็น $O(1)$
  แบบถัวเฉลี่ยตามเดิม
* `expand` ที่คลาสมีให้จะคัดลอกสมาชิกไปไว้ที่ดัชนีเดิมและไม่แตะ `aux` ส่วน
  copy constructor กับ copy assignment คัดลอก `aux` ไปพร้อมข้อมูล ดังนั้น
  สำเนาของสแตกต้องตอบ `min()` ได้ทันทีโดยไม่ต้องไล่หาใหม่ — โปรแกรมตรวจ
  อาศัยข้อนี้

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก $n$ แล้วอ่านสมาชิก $n$ ตัวมา `push` ลง
สแตกตามลำดับ จากนั้นพิมพ์ `top()` และ `min()` แล้วเรียก `pop()` หนึ่งครั้งและ
พิมพ์ `top()` กับ `min()` อีกครั้ง สุดท้ายเรียก `push(5)` และพิมพ์ `min()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และถาม `min()` สลับกับ `push`, `pop`, `top`, `size`
  เป็นแสนครั้ง ดังนั้นถ้าคุณแก้ `push`, `pop` หรือ `top` แล้วทำให้พฤติกรรม
  เดิมเสียไป ระบบจะจับได้
* มีคำสั่งที่ `pop` แล้วถาม `min()` ทันที
* คัดลอกสแตกแล้วถาม `min()` ของสำเนา และไล่ `pop` สำเนาจนว่างพร้อมถาม
  `min()` ทุกขั้น
* สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push` ลงสแตก<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push` ลงสแตก

## Output :

มีทั้งหมด $3$ บรรทัด โดย<br>
บรรทัดแรก : แสดงค่าจาก `top()` และ `min()` คั่นด้วยช่องว่าง<br>
บรรทัดที่สอง : แสดงค่าจาก `top()` และ `min()` อีกครั้ง หลังเรียก `pop()` หนึ่ง
ครั้ง คั่นด้วยช่องว่าง<br>
บรรทัดที่สาม : แสดงค่าจาก `min()` หลังเรียก `push(5)`

## Examples :

### ตัวอย่างที่ 1

```sample-input
5
30 10 20 50 5
```

```sample-output
5 5

5
```

## คำอธิบายตัวอย่างที่ 1

สแตกจากล่างขึ้นบนคือ $30, 10, 20, 50, 5$ ตัวบนสุดคือ $5$ และเป็นตัวที่น้อยที่สุด
ด้วย เมื่อ `pop()` ออกไป สแตกเหลือ $30, 10, 20, 50$ ตัวบนสุดเป็น $50$ และ
`min()` ต้อง <b>กลับไปเป็น</b> $10$ ซึ่งเป็นตัวน้อยที่สุดของสมาชิกที่เหลือ
จากนั้น `push(5)` ทำให้ `min()` เป็น $5$ อีกครั้ง

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด หรือ `-` ถ้าสแตกว่าง |
| `size` | พิมพ์จำนวนสมาชิก |
| `min` | พิมพ์สมาชิกที่น้อยที่สุด หรือ `-` ถ้าสแตกว่าง |
| `copy` | คัดลอกสแตก แล้วถาม `min()` ของสำเนาและไล่ `pop` สำเนาจนว่าง โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold` | เรียก `min()` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |
| `popmin` | `pop` หนึ่งครั้ง แล้วพิมพ์ `min()` ของสแตกที่เหลือ |

คำสั่ง `fold` ไม่พิมพ์อะไรเลย จึงเป็นวิธีที่ถูกที่สุดในแง่ขนาดไฟล์ที่จะถาม
`min()` เป็นแสนครั้ง ชุดข้อมูลใหญ่จึงเต็มไปด้วยคำสั่งนี้ เมื่อหมดคำสั่งของ
บล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกทั้งหมด แล้วพิมพ์สมาชิก $100$ ตัวแรก
ตามด้วยค่า hash ของทุกค่าที่เคยถูกอ่าน

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกเริ่มต้น $n \leq 50{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 130{,}000$ คำสั่ง
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $8 \times 10^9$
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $2 \times 10^6$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
