## คำอธิบาย

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
`T1 first` และ `T2 second`

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
CP::pair<T1, T2> &CP::pair<T1, T2>::operator+=(const CP::pair<T1, T2> &other);
```

ที่บวกสมาชิกของ `other` เข้าไปในสมาชิกของ `*this` ตำแหน่งต่อตำแหน่ง แล้วคืน
**การอ้างอิงไปยัง `*this`** เพื่อให้เขียนต่อกันได้ เช่น `a += b += c` ซึ่งจะ
ทำงานจากขวาไปซ้าย คือบวก `c` เข้า `b` ก่อน แล้วบวกค่าใหม่ของ `b` เข้า `a`

ข้อนี้มีเงื่อนไขด้านประสิทธิภาพ ฟังก์ชันนี้ ต้องแก้ค่าในตัวเองโดยตรง ไม่ใช่
สร้างคู่อันดับใหม่แล้วคัดลอกกลับ เหตุผลคือเมื่อสมาชิกเป็น `std::string` การ
เขียนแบบ

```cpp
CP::pair<T1, T2> sum(first + other.first, second + other.second);
*this = sum;
```

จะคัดลอกข้อความทั้งก้อนที่สะสมมาแล้วทุกครั้งที่เรียก ถ้าเรียก `q` ครั้งเพื่อ
สะสมข้อความยาวรวม `L` ตัวอักษร งานรวมจะเป็น `O(qL)` ซึ่งโตแบบกำลังสอง ในขณะ
ที่การต่อข้อความเข้าไปในที่ด้วย `first += other.first` ใช้เวลารวมเพียง `O(L)`
เพราะ `std::string` ขยายเนื้อที่แบบเท่าตัวและมีค่าเฉลี่ยต่อครั้งเป็น `O(1)`
ต่อหนึ่งตัวอักษรที่เพิ่ม ชุดทดสอบใหญ่ของข้อนี้สะสมข้อความถึง `5 × 10^4` ครั้ง
ลงตัวสะสมตัวเดียว วิธีที่คัดลอกทั้งก้อนทุกครั้งจะใช้เวลาเกินกำหนด

คลาสนี้มีตัวดำเนินการ `+` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยคัดลอก `*this`
ไว้หนึ่งชุดแล้วเรียก `+=` ของคุณกับสำเนานั้น ผลของ `+` จึงต้องตรงกับผลของ `+=`
เสมอ และ `+=` ที่ไม่แก้ค่าใน `*this` จริงจะทำให้ `+` ผิดตามไปด้วย

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `absorb_twice` ที่บวก `other` เข้าไปสอง
ครั้งแล้วคืนการอ้างอิงไปยัง `*this` ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคง
ความหมายเดิมไว้

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ `n` แล้วอ่านคู่อันดับชนิด
`CP::pair<long long,std::string>` มา `n` คู่ โดยบวกสะสมแต่ละคู่เข้าไปในตัวสะสม
หนึ่งตัวและพิมพ์ค่าของตัวสะสมหลังการบวกทุกครั้ง จากนั้นบรรทัดสุดท้ายพิมพ์ค่า
ของตัวสะสมหลังเรียก `absorb_twice` ด้วยคู่สุดท้าย

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน ชุดคำสั่ง แล้วเรียก `+=`, `+`, `absorb_twice`, คอนสตรักเตอร์ และการ
  คัดลอกคู่อันดับสลับกันไปมา
- สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,int>`,
  `CP::pair<long long,std::string>` และ `CP::pair<std::string,std::string>`
- เก็บตัวสะสมไว้สี่ตัว และบวกสะสมลงตัวสะสมเดียวเป็นจำนวนมากในชุดทดสอบใหญ่
  โดยพิมพ์ความยาวและค่าตรวจสอบ (hash) ของตัวสะสมเป็นระยะ ไม่พิมพ์ข้อความทั้ง
  ก้อน
- ทดสอบการเขียนต่อกัน `p += q += r` และ `(p += q) += q` แล้วพิมพ์ค่าของทุกตัว
  ที่เกี่ยวข้อง ซึ่งจับได้ทันทีถ้า `+=` ไม่คืนการอ้างอิงไปยัง `*this`
- เทียบผลของ `A[i] + A[j]` กับผลของสำเนาของ `A[i]` ที่ถูก `+= A[j]` ซึ่งต้อง
  ตรงกันทุกตำแหน่ง

ดังนั้นถ้าคุณแก้ `absorb_twice` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
3
2 ab
5 cd
-1 e
```

### ข้อมูลออก

```sample-output
2 ab
7 abcd
6 abcde
4 abcdeee
```

ตัวสะสมเริ่มจากคอนสตรักเตอร์ว่าง คือ `(0, "")` แล้วบวกสะสมสามคู่เข้าไปตามลำดับ
ได้ `(2, "ab")`, `(7, "abcd")` และ `(6, "abcde")` บรรทัดสุดท้ายคือผลของ
`absorb_twice` ด้วยคู่สุดท้าย `(-1, "e")` ซึ่งบวกเข้าไปอีกสองครั้ง ได้
`(4, "abcdeee")`

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ `n` ตัวที่อ่านจากข้อมูลเข้าและไม่
ถูกแก้อีก พร้อมตัวสะสมสี่ตัวที่เริ่มจากคอนสตรักเตอร์ว่าง หลังจากนั้นจะมีคำสั่ง
ผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `acc k i` | ทำ `S[k] += A[i]` โดยไม่พิมพ์อะไร เป็นคำสั่งหลักของชุดทดสอบใหญ่ |
| `show k` | พิมพ์ความยาวและค่าตรวจสอบของสมาชิกทั้งสองของ `S[k]` |
| `chain i j k` | สร้างตัวแปรท้องถิ่นจาก `A[i]`, `A[j]`, `A[k]` ทำ `p += q += r` แล้วพิมพ์ทั้งสามตัว |
| `twice i j` | สร้าง `p` จาก `A[i]` ทำ `(p += A[j]) += A[j]` แล้วพิมพ์ `p` |
| `agree i j` | พิมพ์ `A[i] + A[j]` และผลของสำเนาของ `A[i]` ที่ถูก `+= A[j]` |
| `reset k` | ตั้ง `S[k]` กลับเป็นคอนสตรักเตอร์ว่าง |
| `absorb i j` | สร้าง `p` จาก `A[i]` เรียก `p.absorb_twice(A[j])` แล้วพิมพ์ `p` |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะพิมพ์ความยาวและค่าตรวจสอบของตัวสะสมทั้งสี่
ตัว ซึ่งขึ้นกับทุกคำสั่ง `acc` ที่ผ่านมาทั้งหมด

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมี `n ≤ 2,000` และ
มีคำสั่งไม่เกิน `q ≤ 60,000` คำสั่ง สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน
`1,000` และสมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 16 ตัว
ค่าสะสมของจำนวนเต็มจึงไม่เกิน `6 × 10^7` และไม่มีการล้นของจำนวนเต็ม ส่วน
ข้อความที่สะสมได้อาจยาวได้ถึงประมาณ `9 × 10^5` ตัวอักษร
