## คำอธิบาย

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บสมาชิก `mSize` ตัวไว้ใน
`mData[0]` ถึง `mData[mSize - 1]` ของอาเรย์ที่จองไว้ `mCap` ช่อง การลบสมาชิก
**ตัวท้าย** ทำได้ง่ายเพราะแค่ลด `mSize` ลงหนึ่ง แต่การลบสมาชิก **ตัวหน้า**
ต้องเลื่อนสมาชิกที่เหลือทั้งหมดมาทางซ้ายหนึ่งช่อง เพราะสมาชิกตัวแรกต้องอยู่ที่
`mData[0]` เสมอ

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::pop_front();
```

ที่ลบสมาชิกตัวแรกของเวกเตอร์ออก โดย

1. สมาชิกที่เหลือต้องเรียงลำดับเดิมและเริ่มที่ `mData[0]` ตามเดิม
2. `size()` ลดลงหนึ่ง แต่ **`capacity()` ต้องไม่เปลี่ยน** ฟังก์ชันนี้ไม่ต้อง
   จองอาเรย์ใหม่และไม่ต้องคืนหน่วยความจำ
3. ถ้าเวกเตอร์ว่างอยู่แล้ว ต้อง **ไม่ทำอะไรเลย** ข้อนี้สำคัญมาก เพราะ
   `mSize` เป็นชนิด `size_t` ซึ่งไม่มีค่าติดลบ การเขียน `mSize--` ตอนที่
   `mSize` เป็น 0 จะทำให้ค่ากลายเป็นจำนวนมหาศาล และเวกเตอร์จะพังทั้งใบ
4. ใช้เวลา O(n) ต่อการเรียกหนึ่งครั้ง ซึ่งเป็นค่าที่ดีที่สุดที่ทำได้สำหรับ
   โครงสร้างแบบอาเรย์

ฟังก์ชัน `push_back` เตรียมไว้ให้แล้วในไฟล์ `{{ds}}` คุณไม่ต้องเขียนเอง

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่าน `n` แล้ว `push_back` สมาชิก `n` ตัวลงใน
`CP::vector<int>` ที่ว่างอยู่ จากนั้นอ่านจำนวน `k` และเรียก `pop_front()` ซ้ำ
`k` ครั้ง แล้วพิมพ์

1. บรรทัดแรก: `size()` และ `capacity()` คั่นด้วยช่องว่าง
2. บรรทัดที่สอง: สมาชิกที่เหลือทั้งหมดตามลำดับ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `pop_front` สลับกับ `push_back`, `resize`,
  `clear`, `operator[]` และการคัดลอกเวกเตอร์ ไม่ใช่เรียกเป็นชุดเดียวตอนท้าย
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
- สั่ง `pop_front` จำนวนครั้ง **มากกว่าจำนวนสมาชิกที่มีอยู่** เพื่อตรวจว่า
  การเรียกบนเวกเตอร์ว่างไม่ทำให้อะไรพัง
- พิมพ์ `capacity()` ทุกครั้งหลังเพิ่มสมาชิก ดังนั้นการจองอาเรย์ใหม่หรือย่อ
  ความจุใน `pop_front` จะถูกจับได้ทันที
- คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การลบผิดตัวหรือเลื่อนข้อมูลขาดไป
  หนึ่งช่องจึงหลบไม่ได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
5
10 20 30 40 50
2
```

### ข้อมูลออก

```sample-output
3 8
30 40 50
```

การ `push_back` ห้าครั้งจากเวกเตอร์ว่างทำให้ความจุขยายเป็น 1, 2, 4, 8 ตามลำดับ
สุดท้ายได้ความจุ 8 และขนาด 5 หลังเรียก `pop_front()` สองครั้งจึงเหลือสมาชิก 3
ตัวคือ `30 40 50` ขณะที่ความจุยังเป็น 8 เท่าเดิม

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ล้างเวกเตอร์แล้ว `push_back` สมาชิก `n` ตัวที่สุ่มจาก `seed` พิมพ์ขนาดและความจุ |
| `2 k` | เรียก `pop_front()` ซ้ำ `k` ครั้ง (ค่า `k` อาจมากกว่าจำนวนสมาชิก) |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4 k seed` | `push_back` เพิ่มอีก `k` ตัว พิมพ์ขนาดและความจุ |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้ว `pop_front` บนสำเนา โดยเวกเตอร์ต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน และถ้าเวกเตอร์
ว่างอยู่คำสั่ง `3` จะพิมพ์เครื่องหมาย `-` เมื่อจบบล็อก grader จะพิมพ์ขนาด
ความจุ และค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกไม่เกิน
100,000 ตัว สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน 10⁶ ชนิด `long long` ไม่
เกิน 2 × 10⁹ และชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 5 ตัว
