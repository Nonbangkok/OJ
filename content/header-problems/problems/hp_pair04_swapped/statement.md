# Pair Swapped

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวที่อาจเป็นชนิดต่างกัน
ไว้ในตัวแปรสมาชิก <b>`T1 first`</b> และ <b>`T2 second`</b>

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
CP::pair<T2, T1> CP::pair<T1, T2>::swapped() const;
```

ที่ <b>สลับตำแหน่งของสมาชิกทั้งสอง</b> แล้วคืนเป็นคู่อันดับใหม่ นั่นคือถ้า `*this` เป็น
$(a, b)$ ผลลัพธ์ต้องเป็นคู่อันดับ $(b, a)$ และตัว `*this` เองต้องไม่เปลี่ยนค่า
เพราะฟังก์ชันนี้เป็น `const`

สิ่งที่ต้องสังเกตคือ <b>ชนิดของผลลัพธ์ไม่ใช่ชนิดเดิม</b> ถ้า `*this` เป็น
`CP::pair<int,std::string>` ผลลัพธ์จะเป็น `CP::pair<std::string,int>`
ลำดับของพารามิเตอร์ชนิดกลับกัน ดังนั้นการพยายามคืนค่าเป็น `*this` หรือสลับค่า
ภายในตัวเองจะคอมไพล์ไม่ผ่าน หรือไม่ก็ให้ชนิดผิด วิธีที่ตรงไปตรงมาคือสร้าง
คู่อันดับใหม่จากคอนสตรักเตอร์สองพารามิเตอร์แล้วคืนออกไป

คลาสนี้ยังมีฟังก์ชัน `round_trip` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยเรียก
`swapped()` สองครั้งติดกัน ครั้งแรกกับ `CP::pair<T1,T2>` และครั้งที่สองกับ
`CP::pair<T2,T1>` ผลลัพธ์จึงต้องกลับมาเท่ากับคู่อันดับเดิมเสมอ นั่นหมายความว่า
`swapped()` ของคุณต้องใช้ได้กับการประกอบชนิดทั้งสองทาง ไม่ใช่ทางเดียว

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `become` ที่ทำให้คู่อันดับนี้กลายเป็นคู่
สลับของคู่อันดับที่รับเข้ามา ซึ่งเขียนไว้ถูกต้องแล้วโดยเรียก `swapped()`
คุณแก้ได้แต่ต้องคงความหมายเดิมไว้

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ $n$ แล้วอ่านคู่อันดับชนิด
`CP::pair<int,std::string>` มา $n$ คู่ สำหรับแต่ละคู่โปรแกรมจะพิมพ์ผลของ
`swapped()` คือข้อความก่อนแล้วตามด้วยจำนวนเต็ม จากนั้นบรรทัดสุดท้ายพิมพ์ผลของ
`round_trip()` ของคู่สุดท้าย ซึ่งต้องกลับมาเป็นจำนวนเต็มก่อนแล้วตามด้วยข้อความ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> แล้วเรียก `swapped`, `round_trip`, `become`, คอนสตรักเตอร์
  และการคัดลอกคู่อันดับสลับกันไปมา
* สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,std::string>`,
  `CP::pair<std::string,long long>` และ `CP::pair<int,int>` สองแบบแรกมีชนิด
  ของสมาชิกไม่เหมือนกัน การคืนชนิดผิดจะคอมไพล์ไม่ผ่าน
* เรียก `swapped()` ซ้อนกันหลายชั้น เช่นสลับผลของการสลับ และสลับสำเนาของผล
  การสลับ

ดังนั้นถ้าคุณแก้ `become` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนคู่อันดับ<br>
$n$ บรรทัดถัดมา : บรรทัดที่ $i$ $(1 \leq i \leq n)$ รับจำนวนเต็ม $a_i$ และ
ข้อความ $s_i$ แทนสมาชิก `first` และ `second` ของคู่อันดับที่ $i$

## Output :

มีทั้งหมด $n + 1$ บรรทัด โดย<br>
$n$ บรรทัดแรก : บรรทัดที่ $i$ $(1 \leq i \leq n)$ แสดงผลของ `swapped()` ของคู่
อันดับที่ $i$ คือข้อความ $s_i$ ตามด้วยจำนวนเต็ม $a_i$<br>
บรรทัดสุดท้าย : แสดงผลของ `round_trip()` ของคู่อันดับที่ $n$ คือจำนวนเต็ม
ตามด้วยข้อความ

## Examples :

### ตัวอย่างที่ 1

```sample-input
3
7 apple
-2 kiwi
0 z
```

```sample-output
apple 7
kiwi -2
z 0
0 z
```

## คำอธิบายตัวอย่างที่ 1

สามบรรทัดแรกคือผลของ `swapped()` ของแต่ละคู่ ซึ่งข้อความย้ายไปอยู่ตำแหน่งแรก
บรรทัดสุดท้ายคือ `round_trip()` ของคู่สุดท้าย $(0, \text{z})$ ซึ่งสลับไปแล้วสลับกลับ
จึงได้คู่เดิม

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ $n$ ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `swap i` | พิมพ์ผลของ `A[i].swapped()` |
| `trip i` | พิมพ์ผลของ `A[i].round_trip()` |
| `become i j` | เรียก `A[i].become(A[j].swapped())` แล้วพิมพ์ค่าของ `A[i]` |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` แล้วพิมพ์ผลของ `A[i].swapped()` |
| `twice i` | คัดลอกผลของ `A[i].swapped()` ด้วย copy constructor แล้วสลับกลับ และพิมพ์ผล |
| `raw i` | พิมพ์ `A[i].first` และ `A[i].second` ตรง ๆ เพื่อยืนยันว่า `swapped()` ไม่แก้ค่าเดิม |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะวนสลับคู่อันดับทุกตัวในอาเรย์ นำผลทั้งหมด
มาคิดเป็นค่าตรวจสอบ (hash) หนึ่งค่า แล้วพิมพ์ออกมา จึงเป็นการตรวจทั้งอาเรย์
ไม่ใช่แค่ตำแหน่งที่ถูกถามถึง

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีคู่อันดับ $n \leq 20{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 40{,}000$ คำสั่ง
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^9$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
