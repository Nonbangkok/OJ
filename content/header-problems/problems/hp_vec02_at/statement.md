## คำอธิบาย

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง แต่ใช้งานจริงเพียง `mSize` ช่องแรก สมาชิกของเวกเตอร์คือ
`mData[0]` ถึง `mData[mSize - 1]` เท่านั้น ช่องตั้งแต่ `mData[mSize]` ถึง
`mData[mCap - 1]` **มีอยู่จริงในหน่วยความจำแต่ไม่ใช่สมาชิก** — ตัวดำเนินการ
`operator[]` ของคลาสนี้ไม่ตรวจอะไรเลย จึงอ่านช่องเหล่านั้นได้เงียบ ๆ ซึ่งเป็น
ที่มาของบั๊กที่หายาก

งานของคุณคือเขียนฟังก์ชันสองเวอร์ชันที่เข้าถึงสมาชิกแบบ **ตรวจขอบเขต**

```cpp
template <typename T>
T &CP::vector<T>::at(size_t index);

template <typename T>
const T &CP::vector<T>::at(size_t index) const;
```

ทั้งสองเวอร์ชันคืน **การอ้างอิง (reference)** ไปยังสมาชิกตำแหน่งที่ `index`
และต้องโยนข้อยกเว้นเมื่อดัชนีอยู่นอกช่วง นั่นคือเมื่อ `index >= size()` ต้อง
โยน `std::out_of_range` ข้อควรระวัง

1. เงื่อนไขคือ `index >= mSize` **ไม่ใช่** `index >= mCap` ดัชนีที่ชี้ไปยัง
   ช่องที่จองไว้แต่ยังไม่ได้ใช้ ต้องถือว่าอยู่นอกช่วง
2. `index == size()` อยู่นอกช่วง (ระวังการใช้ `>` แทน `>=`)
3. เวอร์ชันที่ไม่ใช่ `const` คืน `T &` จึงนำไปเขียนทับได้ เช่น `v.at(3) = 7;`
   ส่วนเวอร์ชัน `const` คืน `const T &` และตัวฟังก์ชันต้องเป็น `const` ด้วย
   เพื่อให้เรียกจากเวกเตอร์ที่เป็น `const` ได้
4. ใช้เวลา **O(1)** ต่อการเรียกหนึ่งครั้ง

คลาสนี้มีฟังก์ชันช่วยแบบ `protected` ชื่อ `rangeCheck(index)` ที่โยน
`std::out_of_range` ให้แล้วเมื่อดัชนีเกินขอบเขต คุณเรียกใช้ได้จาก `at` ทั้ง
สองเวอร์ชัน

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่าน `n` แล้วอ่านสมาชิก `n` ตัวลงใน `CP::vector<int>` โดย
เขียนผ่าน `v.at(i)` จากนั้นพิมพ์ `size()` กับ `capacity()` แล้วอ่านจำนวน
คำถาม `q` กับดัชนี `q` ตัว สำหรับแต่ละดัชนีจะพิมพ์ค่าของสมาชิก หรือพิมพ์
`out_of_range` ถ้าจับข้อยกเว้น `std::out_of_range` ได้

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `at` สลับกับ `resize`, `clear` และการคัดลอก
  เวกเตอร์ โดยดัชนีที่อยู่นอกช่วงจะแทรกอยู่ระหว่างดัชนีที่ถูกต้อง
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
- เรียกทั้งสองเวอร์ชัน: เวอร์ชันปกติใช้เขียนค่าผ่านการอ้างอิงที่คืนมา และ
  เวอร์ชัน `const` ถูกเรียกผ่านตัวแปรอ้างอิงแบบ `const` ถ้าเวอร์ชัน `const`
  หายไปหรือไม่ได้ประกาศเป็น `const` โปรแกรมจะคอมไพล์ไม่ผ่าน
- ยิงดัชนีไปทั้งสามบริเวณ คือ ภายในเวกเตอร์, ช่วง `size()` ถึง
  `capacity() - 1` ที่จองไว้แต่ไม่ใช่สมาชิก, และเลยออกไปไกลจนถึงค่าสูงสุดของ
  `size_t`
- คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว **ผ่าน `at` เวอร์ชัน `const`** ดังนั้น
  `at` ที่คืนช่องผิดจะถูกจับได้ทุกสมาชิก ไม่ใช่เฉพาะที่สุ่มถาม

### ข้อมูลเข้า

```sample-input
3

4

```

```sample-output
3 3
10
30
out_of_range
out_of_range
```

เวกเตอร์ที่สร้างด้วย `CP::vector<int> v(3)` มีขนาดและความจุเท่ากับ 3 ดัชนี 0
กับ 2 จึงอยู่ในช่วง ส่วนดัชนี 3 ซึ่งเท่ากับ `size()` พอดี และดัชนี 100 อยู่
นอกช่วงทั้งคู่

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` พิมพ์ขนาดและความจุ |
| `2 i` | อ่านสมาชิกตำแหน่ง `i` ผ่าน `at` เวอร์ชันปกติ |
| `3 i x` | เขียน `v.at(i) = x` แล้วพิมพ์ `W` |
| `4 i` | อ่านสมาชิกตำแหน่ง `i` ผ่าน `at` เวอร์ชัน `const` |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ด้วย copy constructor และ copy assignment แล้วตรวจสำเนาด้วย `at` |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมดที่อ่านผ่าน `at` |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |

ทุกคำสั่งที่เข้าถึงข้อมูลจะพิมพ์ค่าที่ได้ หรือพิมพ์ `X` เมื่อจับ
`std::out_of_range` ได้ ดังนั้นลำดับของ `X` ที่ออกมาคือคำตอบของข้อนี้ เมื่อจบ
บล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกไม่เกิน
1,000,000 ตัว ดัชนีที่ถามมีค่าตั้งแต่ 0 ถึง 2⁶⁴ − 1 สมาชิกชนิด `int` มีค่า
สัมบูรณ์ไม่เกิน 10⁶ ชนิด `long long` ไม่เกิน 2 × 10⁹ และชนิดข้อความเป็น
ตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 5 ตัว
