# Stack At

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก สมาชิกตัวที่ใส่เข้ามาก่อนอยู่ที่
ดัชนีน้อย และสมาชิกตัวบนสุดของสแตกอยู่ที่ `mData[mSize - 1]`
ฟังก์ชัน `push`, `pop` และ `top` เขียนไว้ให้แล้วในไฟล์ `{{ds}}`

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
const T &CP::stack<T>::at(size_t k) const;
```

ที่คืนค่าสมาชิกลำดับที่ $k$ เมื่อ <b>นับจากตัวบนสุดลงไป</b> โดยให้ $k = 0$
หมายถึงตัวบนสุด (ค่าเดียวกับ `top()`), $k = 1$ หมายถึงตัวที่อยู่ใต้ตัวบนสุด
และ $k = n - 1$ เมื่อ $n$ คือ `size()` หมายถึงตัวล่างสุดของสแตก ต้องใช้เวลา
<b>$O(1)$</b> ต่อการเรียกหนึ่งครั้ง และคืนค่าเป็นการอ้างอิง (reference)
ไปยังสมาชิกตัวนั้น

สิ่งที่ต้องคิดคือ $k$ นับสวนทางกับดัชนีของ `mData` ดัชนีในอาเรย์จึงเป็นการ
สะท้อนกลับของ $k$ ไม่ใช่ $k$ ตรง ๆ และ <b>ห้ามไล่วนลูป</b> เพราะต้องได้เวลา
$O(1)$ แม้ $k$ จะใหญ่ถึงหลักหมื่น

โปรแกรมของผู้ออกข้อสอบจะเรียก `at(k)` เฉพาะเมื่อ $k < n$ เมื่อ $n$ คือ
`size()` เท่านั้น คุณจึงไม่ต้องตรวจขอบเขตหรือโยน exception

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก $n$ แล้วอ่านสมาชิก $n$ ตัวมา `push` ลง
สแตกตามลำดับ จากนั้นพิมพ์ `at(0)`, `at(1)` และ `at(size() - 1)` แล้วเรียก
`pop()` หนึ่งครั้งและพิมพ์ `at(0)` กับ `at(size() - 1)` อีกครั้ง ตามด้วย
จำนวนสมาชิกที่เหลือจาก `size()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `at(k)` สลับกับ `push`, `pop`, `top`, `size`
  หลายครั้ง ค่า $k$ เดิมจึงหมายถึงสมาชิกต่างตัวกันหลังสแตกเปลี่ยนไป
* ใช้ค่า $k$ ทั้งสองปลาย คือ $k = 0$ และ $k = \text{size}() - 1$ บ่อยเป็นพิเศษ
* มีคำสั่งที่ไล่อ่านทั้งสแตกด้วย `at(0)` ถึง `at(size() - 1)` แล้วนำทุกค่าไป
  รวมเป็น hash ดังนั้น `at()` ที่ถูกเฉพาะใกล้ยอดสแตกจะไม่ผ่าน
* สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`
* คัดลอกสแตกด้วย copy constructor และ copy assignment แล้วตรวจว่าสแตกต้นฉบับ
  ไม่เปลี่ยน

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push` ลงสแตก<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push` ลงสแตก

## Output :

มีทั้งหมด $3$ บรรทัด โดย<br>
บรรทัดแรก : แสดงค่า `at(0)`, `at(1)` และ `at(size() - 1)` คั่นด้วยช่องว่าง<br>
บรรทัดที่สอง : แสดงค่า `at(0)` และ `at(size() - 1)` หลังเรียก `pop()` หนึ่งครั้ง
คั่นด้วยช่องว่าง<br>
บรรทัดที่สาม : แสดงจำนวนสมาชิกที่เหลือจาก `size()`

## Examples :

### ตัวอย่างที่ 1

```sample-input
5
10 20 30 40 50
```

```sample-output
50 40 10
40 10
4
```

## คำอธิบายตัวอย่างที่ 1

สแตกจากล่างขึ้นบนคือ $10, 20, 30, 40, 50$ ดังนั้น `at(0)` คือ $50$,
`at(1)` คือ $40$ และ `at(4)` ซึ่งเป็นตัวล่างสุดคือ $10$ หลัง `pop()` หนึ่งครั้ง
`at(0)` กลายเป็น $40$ ส่วนตัวล่างสุดยังเป็น $10$ และเหลือสมาชิก $4$ ตัว

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด |
| `at k` | พิมพ์ `at(k)` โดยข้อมูลรับประกันว่า `k < size()` |
| `size` | พิมพ์จำนวนสมาชิก |
| `copy` | คัดลอกสแตก แล้วพิมพ์และไล่อ่านสำเนาด้วย `at()` โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold k` | เรียก `at(k)` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |
| `sweep` | ไล่อ่าน `at(0)` ถึง `at(size() - 1)` แล้วนำทุกค่าไปรวมใน hash |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากสแตกทั้งหมด แล้ว
พิมพ์สมาชิก $100$ ตัวแรกที่นำออก ตามด้วยค่า hash ของสมาชิกทุกตัวที่เคยถูกอ่าน

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกเริ่มต้น $n \leq 50{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 120{,}000$ คำสั่ง
* สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
