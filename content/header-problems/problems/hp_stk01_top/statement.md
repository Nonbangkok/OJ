## คำอธิบาย

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก สมาชิกตัวที่ใส่เข้ามาก่อนอยู่ที่
ดัชนีน้อย และสมาชิกตัวที่ใส่เข้ามาล่าสุด (ตัวบนสุดของสแตก) อยู่ที่ช่องท้ายสุด
ที่กำลังใช้งาน คลาสนี้ยังมีตัวแปรสมาชิก `int aux` ซึ่งโจทย์ข้อนี้ยังไม่ต้องใช้

ฟังก์ชัน `push` และ `pop` เขียนไว้ให้แล้วในไฟล์ `{{ds}}`

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
const T &CP::stack<T>::top() const;
```

ที่ **คืนค่าสมาชิกที่อยู่บนสุดของสแตก** โดยใช้เวลา **O(1)** และคืนค่าเป็น
**การอ้างอิง (reference)** ไปยังสมาชิกตัวนั้นในอาเรย์ ไม่ใช่สำเนา

ข้อควรระวังสองข้อ

- ฟังก์ชันนี้เป็น `const` จึงห้ามแก้ไขตัวแปรสมาชิกใด ๆ การเรียก `top()`
  ไม่ใช่การนำสมาชิกออกจากสแตก เรียกซ้ำกี่ครั้งก็ต้องได้ค่าเดิม
- โปรแกรมของผู้ออกข้อสอบจะเรียก `top()` เฉพาะเมื่อสแตกไม่ว่าง (ตรวจด้วย
  `empty()` ก่อน) คุณจึงไม่ต้องจัดการกรณีสแตกว่าง

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก `n` แล้วอ่านสมาชิก `n` ตัวมา `push` ลงสแตก
ตามลำดับ จากนั้นพิมพ์

1. บรรทัดแรก: ค่าที่ได้จาก `top()`
2. บรรทัดที่สอง: ค่าที่ได้จาก `top()` หลังเรียก `pop()` หนึ่งครั้ง
3. บรรทัดที่สาม: จำนวนสมาชิกที่เหลือจาก `size()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `top()` สลับกับ `push`, `pop`, `size` หลายครั้ง
  ไม่ใช่เรียกตอนท้ายเพียงครั้งเดียว
- สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`
- คัดลอกสแตกด้วย copy constructor และ copy assignment แล้วตรวจว่าสแตกต้นฉบับ
  ไม่เปลี่ยน

ดังนั้นถ้า `top()` ของคุณเผลอเปลี่ยนสถานะของสแตก (เช่นลด `mSize`) ระบบจะ
จับได้ทันที

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
5
10 20 30 40 50
```

### ข้อมูลออก

```sample-output
50
40
4
```

สมาชิกตัวบนสุดคือ `50` ซึ่งเป็นตัวที่ `push` เข้ามาล่าสุด หลัง `pop()` หนึ่ง
ครั้ง ตัวบนสุดจึงกลายเป็น `40` และเหลือสมาชิก `4` ตัว

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด |
| `size` | พิมพ์จำนวนสมาชิก |
| `copy` | คัดลอกสแตก แล้วพิมพ์ข้อมูลของสำเนา โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold` | เรียก `top()` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากสแตกทั้งหมดด้วย
`top()` และ `pop()` แล้วพิมพ์สมาชิก 100 ตัวแรกที่นำออก ตามด้วยค่า hash ของ
สมาชิกทุกตัวที่เคยถูกอ่าน จึงเป็นการตรวจลำดับทั้งสแตก ไม่ใช่แค่ตัวบนสุด

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกเริ่มต้น
`n` ตัว โดย `n ≤ 50,000` และมีคำสั่งไม่เกิน `q ≤ 120,000` คำสั่ง สมาชิกชนิด
จำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน 4 × 10⁹ และสมาชิกชนิดข้อความเป็นตัวอักษร
ภาษาอังกฤษตัวเล็กยาวไม่เกิน 6 ตัว
