## คำอธิบาย

การแทรกสมาชิกหนึ่งตัวเข้า `CP::vector<T>` ต้องเลื่อนสมาชิกตั้งแต่ตำแหน่งนั้น
ไปทางขวาหนึ่งช่อง ถ้าต้องแทรกข้อมูล `m` ตัวที่ตำแหน่งเดียวกันแล้วเรียก
ฟังก์ชันแทรกทีละตัว `m` ครั้ง ข้อมูลส่วนท้ายจะถูกเลื่อนซ้ำ `m` รอบ เวลารวม
เป็น O(m × n) ทั้งที่ควรเลื่อนเพียงรอบเดียวด้วยระยะ `m` ช่อง

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::range_insert(size_t pos, const std::vector<T> &values);
```

ที่แทรกสมาชิกทั้งก้อนเข้าไปก่อนตำแหน่ง `pos` โดย

1. สมาชิกใน `values` ต้องเรียงตามลำดับเดิมของมัน ต่อด้วยสมาชิกที่เคยอยู่
   ตั้งแต่ตำแหน่ง `pos` เป็นต้นไป `size()` เพิ่มขึ้นเท่ากับ `values.size()`
2. `pos == size()` หมายถึงต่อท้ายเวกเตอร์ ซึ่งถูกต้อง ส่วน `pos > size()`
   ให้ **ไม่ทำอะไรเลย** และถ้า `values` ว่างก็ไม่ทำอะไรเช่นกัน
3. **ต้องใช้เวลา O(n + m)** นั่นคือ
   - ขยายความจุ **ครั้งเดียว** ด้วย `ensureCapacity(mSize + m)` ไม่ใช่ขยาย
     `m` ครั้ง
   - เลื่อนข้อมูลส่วนท้ายรอบเดียวด้วยระยะ `m` ช่อง โดยต้องเลื่อน **จากตัว
     ท้ายไปตัวหน้า** ไม่อย่างนั้นข้อมูลจะทับกันเองเมื่อ `m` น้อยกว่าความยาว
     ของส่วนท้าย
4. ไม่ต้องใช้หน่วยความจำเพิ่มนอกจากการขยายความจุครั้งนั้น

สังเกตว่าการต่อท้าย (`pos == size()`) ไม่ต้องเลื่อนอะไรเลย ชุดทดสอบที่ตัดสิน
ข้อนี้จึงแทรกก้อนใหญ่ไว้ที่ **ต้นหรือกลาง** เวกเตอร์

ไฟล์ `main.cpp` ของทั้งผู้ออกข้อสอบและของที่ให้ดาวน์โหลด `#include <vector>`

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่าน `n` และสมาชิก `n` ตัวลงใน `CP::vector<int>` จากนั้น
อ่าน `pos` กับ `m` และค่าอีก `m` ตัวใส่ `std::vector<int>` แล้วเรียก
`range_insert(pos, values)` หนึ่งครั้ง และพิมพ์

1. บรรทัดแรก: `size()` ใหม่
2. บรรทัดที่สอง: สมาชิกทั้งหมดตามลำดับ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `range_insert` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
- **สร้างก้อนข้อมูลขึ้นเองภายในโปรแกรม** จากค่า seed ดังนั้นคำสั่งบรรทัดเดียว
  แทรกข้อมูลได้ถึงสองแสนตัว
- แทรกที่ตำแหน่ง 0, ตรงกลาง, ที่ `size()` พอดี, ที่ตำแหน่งเลย `size()`
  (ต้องไม่ทำอะไร) และด้วยก้อนว่าง
- คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การเลื่อนข้อมูลทับกันเองหรือวาง
  ก้อนใหม่สลับลำดับจึงหลบไม่ได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
5
10 20 30 40 50
2 3
7 8 9
```

### ข้อมูลออก

```sample-output
8
10 20 7 8 9 30 40 50
```

ก้อน `7 8 9` ถูกแทรกไว้ก่อนตำแหน่ง 2 สมาชิก `30 40 50` ที่เคยอยู่ตั้งแต่
ตำแหน่ง 2 จึงเลื่อนไปทางขวาสามช่องพร้อมกันในรอบเดียว

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` |
| `2 pos m seed` | สร้างก้อนข้อมูล `m` ตัวจาก `seed` แล้วเรียก `range_insert(pos, …)` |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4 m seed` | แทรกก้อน `m` ตัวที่ท้ายเวกเตอร์ |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วแทรกก้อนเล็กบนสำเนา โดยต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10 pos` | เรียก `range_insert(pos, …)` ด้วยก้อนว่าง (ต้องไม่เปลี่ยนอะไร) |
| `11 m seed` | แทรกก้อน `m` ตัวที่ตำแหน่ง 0 |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน ส่วนค่า `pos`
ของคำสั่ง `2` และ `10` **ไม่ถูกปรับ** เพราะตำแหน่งที่เลยขอบเขตเป็นส่วนหนึ่ง
ของสิ่งที่ตรวจ เมื่อจบบล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกรวมไม่เกิน
ประมาณ 10⁶ ตัว และก้อนที่แทรกแต่ละครั้งมีไม่เกิน 2 × 10⁵ ตัว สมาชิกชนิด
`int` มีค่าสัมบูรณ์ไม่เกิน 10⁶ ชนิด `long long` ไม่เกิน 2 × 10⁹ และชนิด
ข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 5 ตัว
