# Pair Normalize

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
<b>`T1 first`</b> และ <b>`T2 second`</b>

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
void CP::pair<T1, T2>::normalize();
```

ที่จัดเรียงสมาชิกของคู่อันดับให้ `first` ไม่มากกว่า `second` ถ้าตอนนี้
`first` มากกว่า `second` อยู่ ให้สลับค่าของสมาชิกทั้งสอง ถ้าไม่ใช่ก็ไม่ต้อง
ทำอะไร

ฟังก์ชันนี้ใช้ได้เฉพาะเมื่อ `T1` และ `T2` เป็นชนิดเดียวกัน เพราะต้องนำค่าจาก
ตำแหน่งหนึ่งไปใส่อีกตำแหน่งหนึ่ง โปรแกรมที่ระบบใช้ตรวจจึงเรียกฟังก์ชันนี้กับ
คู่อันดับที่สมาชิกทั้งสองเป็นชนิดเดียวกันเท่านั้น และการสลับต้องใช้ตัวแปร
ชั่วคราวช่วย การเขียน `first = second; second = first;` จะทำให้ค่าเดิมของ
`first` หายไป

สมบัติที่สำคัญของฟังก์ชันนี้คือ <b>idempotent</b> นั่นคือเมื่อเรียกครบหนึ่งครั้ง
แล้ว เรียกซ้ำอีกครั้งต้องไม่เปลี่ยนอะไรอีก คลาสนี้มีฟังก์ชัน `normalize_twice`
ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยเรียก `normalize()` สองครั้งติดกัน
ผลลัพธ์จึงต้องเท่ากับการเรียกครั้งเดียวเสมอ การเขียน `normalize` ให้สลับค่าทุก
ครั้งโดยไม่ตรวจเงื่อนไขก่อนจะผ่านการทดสอบที่เรียกครั้งเดียว แต่จะพลาดที่นี่

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `sorted` ที่ตอบว่าคู่อันดับนี้เรียงอยู่
แล้วหรือไม่ ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมายเดิมไว้ หลัง
เรียก `normalize()` ฟังก์ชันนี้ต้องคืนค่าจริงเสมอ

ชนิดของสมาชิกรับประกันว่ามีตัวดำเนินการ `<` ของตัวเองอยู่แล้ว

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ $n$ แล้วอ่านคู่อันดับชนิด
`CP::pair<int,int>` มา $n$ คู่ สำหรับแต่ละคู่โปรแกรมจะพิมพ์หนึ่งบรรทัด
ประกอบด้วยสี่ค่า คือผลของ `sorted()` ก่อนจัดเรียง ค่าของ `first` และ `second`
หลังเรียก `normalize()` และผลของ `sorted()` หลังจัดเรียง

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> แล้วเรียก `normalize`, `normalize_twice`, `sorted`,
  คอนสตรักเตอร์ และการคัดลอกคู่อันดับสลับกันไปมา
* สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,int>`,
  `CP::pair<std::string,std::string>` และ `CP::pair<long long,long long>`
* เรียก `normalize()` สองครั้งติดกันบนคู่เดียวกัน แล้วพิมพ์ค่าหลังครั้งที่หนึ่ง
  และหลังครั้งที่สองในบรรทัดเดียวกัน ทั้งสองค่าจึงต้องเหมือนกันทุกตัวอักษร
* จัดเรียงสำเนาของคู่อันดับ แล้วพิมพ์ทั้งสำเนาและต้นฉบับ ซึ่งต้นฉบับต้องไม่
  เปลี่ยน

ดังนั้นถ้าคุณแก้ `sorted` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนคู่อันดับ<br>
$n$ บรรทัดถัดมา : บรรทัดที่ $i$ $(1 \leq i \leq n)$ รับจำนวนเต็ม $a_i$ และ
$b_i$ แทนสมาชิก `first` และ `second` ของคู่อันดับที่ $i$

## Output :

มีทั้งหมด $n$ บรรทัด โดย<br>
บรรทัดที่ $i$ $(1 \leq i \leq n)$ แสดงจำนวนเต็มสี่จำนวน คือผลของ `sorted()`
ของคู่อันดับที่ $i$ ก่อนจัดเรียง ค่า `first` และ `second` หลังเรียก
`normalize()` และผลของ `sorted()` หลังจัดเรียง โดย `1` แทนจริงและ `0` แทนเท็จ

## Examples :

### ตัวอย่างที่ 1

```sample-input
3
5 2
-1 -1
0 8
```

```sample-output
0 2 5 1
1 -1 -1 1
1 0 8 1
```

## คำอธิบายตัวอย่างที่ 1

คู่แรก $(5, 2)$ ยังไม่เรียง `sorted()` จึงเป็นเท็จ และหลังจัดเรียงได้ $(2, 5)$
คู่ที่สองมีสมาชิกเท่ากัน ซึ่งนับว่าเรียงอยู่แล้วเพราะเงื่อนไขคือ `first` ไม่
มากกว่า `second` จึงไม่มีการสลับ และคู่ที่สาม $(0, 8)$ เรียงอยู่แล้วเช่นกัน

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ $n$ ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `norm i` | เรียก `A[i].normalize()` พิมพ์ค่า แล้วเรียกอีกครั้งและพิมพ์ค่าซ้ำในบรรทัดเดียวกัน |
| `twice i` | เรียก `A[i].normalize_twice()` แล้วพิมพ์ค่าและผลของ `sorted()` |
| `ask i` | พิมพ์ค่าของ `A[i]` และผลของ `sorted()` โดยไม่จัดเรียง |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` แล้วจัดเรียงและพิมพ์ค่า |
| `from i j` | ทำ `A[i] = A[j]` จัดเรียงเฉพาะ `A[i]` แล้วพิมพ์ทั้ง `A[i]` และ `A[j]` |
| `copy i` | จัดเรียงสำเนาของ `A[i]` แล้วพิมพ์ทั้งสำเนาและต้นฉบับ |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะจัดเรียงทุกตัวในอาเรย์ นับจำนวนตัวที่
`sorted()` เป็นจริง (ซึ่งต้องเท่ากับจำนวนตัวทั้งหมด) แล้วนำค่าทั้งหมดมาคิดเป็น
ค่าตรวจสอบ (hash) หนึ่งค่าและพิมพ์ออกมา

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีคู่อันดับ $n \leq 20{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 30{,}000$ คำสั่ง
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^9$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
