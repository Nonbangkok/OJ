## คำอธิบาย

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
`T1 first` และ `T2 second`

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
bool CP::pair<T1, T2>::operator<(const CP::pair<T1, T2> &other) const;
```

ที่เปรียบเทียบคู่อันดับสองคู่แบบ **พจนานุกรม** (lexicographic) นั่นคือ
เทียบสมาชิกตัวแรกก่อน ถ้าเท่ากันจึงเทียบสมาชิกตัวที่สอง เขียนเป็นเงื่อนไขได้ว่า
`*this` น้อยกว่า `other` เมื่อ

- `first` ของ `*this` น้อยกว่า `first` ของ `other` หรือ
- `first` ของทั้งสองคู่เท่ากัน และ `second` ของ `*this` น้อยกว่า `second` ของ
  `other`

ถ้าคู่อันดับทั้งสองเท่ากันทุกตำแหน่ง ต้องคืนค่า `false` เพราะไม่มีคู่ใดน้อยกว่า
อีกคู่

ชนิด `T1` และ `T2` รับประกันว่ามีตัวดำเนินการ `<` และ `==` ของตัวเองอยู่แล้ว
ข้อควรระวังคือกรณีที่ `first` เท่ากัน ซึ่งเป็นกรณีที่ตัดสินผลด้วย `second`
เท่านั้น ข้อนี้มีข้อมูลทดสอบที่ `first` ซ้ำกันเป็นจำนวนมาก

คลาสนี้ยังมีตัวดำเนินการ `>` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยนิยามว่า
`a > b` คือ `b < a` จึงเรียกใช้ `<` ของคุณเสมอ และในไฟล์ `{{submission}}`
มีฟังก์ชัน `make_min` ที่เปลี่ยนค่าของคู่อันดับให้เป็นคู่ที่น้อยกว่าระหว่าง
ตัวมันเองกับคู่ที่รับเข้ามา ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมาย
เดิมไว้

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ `n` แล้วอ่านคู่อันดับชนิด
`CP::pair<int,int>` มา `n` คู่ คู่แรกถูกใช้เป็นคู่อ้างอิง สำหรับทุกคู่ที่อ่าน
เข้ามาโปรแกรมจะพิมพ์ผลของ `<` และ `>` เทียบกับคู่อ้างอิงเป็น `1` หรือ `0`
หนึ่งบรรทัดต่อหนึ่งคู่ จากนั้นบรรทัดสุดท้ายพิมพ์คู่อันดับที่น้อยที่สุดในบรรดา
คู่ทั้งหมด ซึ่งหาด้วย `make_min`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน ชุดคำสั่ง แล้วเรียก `<`, `>`, `make_min`, คอนสตรักเตอร์ และการคัดลอก
  คู่อันดับสลับกันไปมา
- สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,int>`,
  `CP::pair<std::string,int>` และ `CP::pair<int,std::string>`
- พิมพ์ผลของ `<` และ `>` คู่กันทุกครั้ง คู่อันดับที่เท่ากันจึงต้องได้ `0 0`
  และคู่ที่ต่างกันต้องได้ `1 0` หรือ `0 1`

ดังนั้นถ้าคุณแก้ `make_min` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
4
3 1
3 0
1 9
3 1
```

### ข้อมูลออก

```sample-output
0 0
1 0
1 0
0 0
1 9
```

คู่อ้างอิงคือ `(3, 1)` คู่ที่สอง `(3, 0)` มี `first` เท่ากันแต่ `second` น้อยกว่า
จึงน้อยกว่าคู่อ้างอิง คู่ที่สาม `(1, 9)` มี `first` น้อยกว่าจึงน้อยกว่าทันที
และคู่ที่สี่เท่ากับคู่อ้างอิงพอดีจึงได้ `0 0` คู่ที่น้อยที่สุดคือ `(1, 9)`

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ `n` ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `cmp i j` | พิมพ์ผลของ `A[i] < A[j]` และ `A[i] > A[j]` |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` ด้วยการคัดลอก |
| `min i j` | เรียก `A[i].make_min(A[j])` แล้วพิมพ์ค่าของ `A[i]` |
| `temp i a b` | เทียบ `A[i]` กับคู่อันดับชั่วคราวที่สร้างจาก `(a, b)` |
| `zero i` | เทียบ `A[i]` กับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |
| `argmin` | พิมพ์ตำแหน่งและค่าของคู่อันดับที่น้อยที่สุดในอาเรย์ |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะวนเทียบคู่อันดับที่อยู่ติดกันทั้งอาเรย์
แล้วพิมพ์จำนวนตำแหน่งที่เรียงขึ้นและจำนวนตำแหน่งที่เรียงลง ผลต่างของสองจำนวนนี้
จะเปลี่ยนไปทันทีถ้าการตัดสินกรณี `first` เท่ากันผิด

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมี `n ≤ 20,000` และ
มีคำสั่งไม่เกิน `q ≤ 40,000` คำสั่ง สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน
`10^9` และสมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 6 ตัว
