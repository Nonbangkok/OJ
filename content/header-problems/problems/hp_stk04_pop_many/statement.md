# Stack Pop Many

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก และสมาชิกตัวบนสุดของสแตกอยู่ที่
`mData[mSize - 1]` ฟังก์ชัน `push`, `pop()` และ `top` เขียนไว้ให้แล้วในไฟล์
`{{ds}}`

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชันที่เป็น <b>overload</b> อีกแบบหนึ่งของ `pop`

```cpp
template <typename T>
void CP::stack<T>::pop(size_t k);
```

ที่ <b>นำสมาชิกออกจากสแตกพร้อมกัน $k$ ตัว</b> นับจากตัวบนสุดลงไป โดย

* ถ้า $k = 0$ สแตกต้องไม่เปลี่ยนแปลงเลย
* ถ้า $k \geq \text{size}()$ ให้สแตกกลายเป็นสแตกว่าง (ไม่ใช่ข้อผิดพลาด)
* หลังเรียกเสร็จ `size()` ต้องได้ค่าที่ถูกต้อง และ `top()` ต้องคืนสมาชิกตัวที่
  ควรขึ้นมาอยู่บนสุด

กับดักของข้อนี้คือชนิด `size_t` ซึ่งเป็นจำนวนเต็ม <b>ไม่มีเครื่องหมาย</b> การ
เขียน `mSize -= k` ตรง ๆ เมื่อ $k$ มากกว่า `mSize` จะไม่ได้ค่าติดลบ แต่จะวน
กลับไปเป็นจำนวนมหาศาล ทำให้สแตกคิดว่ามีสมาชิกเป็นหมื่นล้านตัว ข้อมูลทดสอบมี
$k$ ที่ใหญ่กว่าจำนวนสมาชิกจริงอยู่หลายครั้ง และมี $k$ ที่ใหญ่ถึง $4 \times 10^9$

สังเกตว่าการนำสมาชิกออกไม่จำเป็นต้องลบข้อมูลในอาเรย์ เพราะช่องที่อยู่เลย
`mSize` ไปแล้วถือว่าไม่เป็นส่วนหนึ่งของสแตกอีก

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก $n$ แล้วอ่านสมาชิก $n$ ตัวมา `push` ลง
สแตกตามลำดับ จากนั้นพิมพ์ค่าจาก `top()` แล้วเรียก `pop(2)` และพิมพ์ `top()`
กับ `size()` แล้วเรียก `pop(1000)` ซึ่งมากกว่าจำนวนสมาชิกที่เหลืออยู่ และพิมพ์
`size()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `pop(k)` สลับกับ `push`, `pop()`, `top`,
  `size` หลายครั้ง และพิมพ์จำนวนสมาชิกที่เหลือทุกครั้งหลังเรียก `pop(k)`
* ใช้ค่า $k$ ที่เป็นจุดเปลี่ยนทั้งหมด คือ $0$, $1$, $\text{size}() - 1$,
  $\text{size}()$, $\text{size}() + 1$ และค่าระดับพันล้าน
* สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`
* คัดลอกสแตกด้วย copy constructor และ copy assignment แล้วตรวจว่าสแตกต้นฉบับ
  ไม่เปลี่ยน

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push` ลงสแตก<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push` ลงสแตก

## Output :

มีทั้งหมด $3$ บรรทัด โดย<br>
บรรทัดแรก : แสดงค่าจาก `top()`<br>
บรรทัดที่สอง : แสดงค่าจาก `top()` และ `size()` หลังเรียก `pop(2)` คั่นด้วย
ช่องว่าง<br>
บรรทัดที่สาม : แสดงค่าจาก `size()` หลังเรียก `pop(1000)` ซึ่งมากกว่าจำนวน
สมาชิกที่เหลืออยู่

## Examples :

### ตัวอย่างที่ 1

```sample-input
5
10 20 30 40 50
```

```sample-output
50
30 3
0
```

## คำอธิบายตัวอย่างที่ 1

สแตกจากล่างขึ้นบนคือ $10, 20, 30, 40, 50$ ตัวบนสุดจึงเป็น $50$ หลัง `pop(2)`
สมาชิก $50$ และ $40$ ถูกนำออก เหลือ $10, 20, 30$ ตัวบนสุดเป็น $30$ และมีสมาชิก
$3$ ตัว จากนั้น `pop(1000)` มากกว่าจำนวนสมาชิกที่เหลือ สแตกจึงว่างและ
`size()` เป็น $0$

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | เรียก `pop()` นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด หรือ `-` ถ้าสแตกว่าง |
| `size` | พิมพ์จำนวนสมาชิก |
| `pop k` | เรียก `pop(k)` แล้วพิมพ์จำนวนสมาชิกที่เหลือ |
| `copy` | คัดลอกสแตก แล้วพิมพ์ข้อมูลของสำเนา โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold` | เรียก `top()` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากสแตกทั้งหมด แล้ว
พิมพ์สมาชิก $100$ ตัวแรกที่นำออก ตามด้วยค่า hash ของสมาชิกทุกตัวที่เคยถูกอ่าน
จึงเป็นการตรวจว่า `pop(k)` ตัดสมาชิกออกถูกตัว ไม่ใช่แค่ถูกจำนวน

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกเริ่มต้น $n \leq 50{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 120{,}000$ คำสั่ง
* ค่า $k$ ของคำสั่ง `pop k` ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
