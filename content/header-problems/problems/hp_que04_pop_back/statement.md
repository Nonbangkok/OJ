## คำอธิบาย

คลาส `CP::queue<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลด้วย **ring buffer**: อาเรย์
`mData` ขนาด `mCap` ช่อง เก็บสมาชิก `mSize` ตัว โดยสมาชิกตัวหน้าสุดอยู่ที่
`mData[mFront]` และตัวถัดไปวนไปทางขวาแบบวงกลม เมื่อเดินเลยช่องสุดท้ายของ
อาเรย์แล้วจะวนกลับมาที่ช่องที่ 0

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::queue<T>::pop_back();
```

ที่นำ **สมาชิกตัวหลังสุด** ออกจากคิว สมาชิกที่เหลือต้องยังเรียงเหมือนเดิมและ
ตัวหน้าสุดต้องยังเป็นตัวเดิม ถ้าเรียกกับคิวที่ว่างอยู่แล้วต้องไม่ทำอะไรเลย
และคิวต้องยังใช้งานต่อได้ตามปกติ

ข้อนี้เป็นเรื่องของการมองให้ออกว่า **ไม่ต้องย้ายข้อมูลเลย** ขอบเขตของคิวใน
อาเรย์ถูกกำหนดด้วย `mFront` กับ `mSize` เท่านั้น ตัวหลังสุดอยู่ที่ระยะ
`mSize - 1` จาก `mFront` ดังนั้นการตัดมันออกคือการบอกว่าคิวสั้นลงหนึ่งตัว
ไม่ใช่การเลื่อนอะไร และ `mFront` ต้องอยู่นิ่ง เพราะถ้าขยับ `mFront` จะกลาย
เป็นการเอาตัว **หน้าสุด** ออกแทน

สิ่งที่พลาดกันบ่อยคือกรณีคิวว่าง ตัวแปร `mSize` มีชนิด `size_t` ซึ่งเป็น
จำนวนเต็มไม่มีเครื่องหมาย การลดค่ามันตอนที่เป็น 0 จะไม่ได้ `-1` แต่จะวนไป
เป็นเลขมหาศาล คิวจะอ้างว่าตัวเองมีสมาชิกเป็นหมื่นล้านล้านตัว และทุกคำสั่ง
ถัดจากนั้นก็พังตามไปด้วย ผู้ออกข้อสอบเรียก `pop_back` กับคิวว่างแน่นอน

ฟังก์ชันนี้ต้องทำงานในเวลา O(1) การไล่เดินจาก `mFront` ไปหาช่องของตัวหลังสุด
ก่อนจะตัดมันออกให้คำตอบถูกต้อง แต่ใช้เวลา O(size()) ทุกครั้ง และจะได้ Time
Limit Exceeded ในชุดทดสอบ 30% สุดท้าย

ฟังก์ชัน `front`, `back`, `push` และ `pop` เขียนไว้ให้เรียบร้อยแล้วในไฟล์
`{{ds}}` คุณไม่ต้องแก้และแก้ไม่ได้ ไฟล์ `{{submission}}` จึงมีเพียงฟังก์ชัน
`pop_back` ที่ยังว่างอยู่ให้คุณเติม นอกจากนี้คลาสยังมีตัวแปรสมาชิก `int aux`
ซึ่งข้อนี้ไม่จำเป็นต้องใช้

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก `n` แล้วอ่านสมาชิก `n` ตัวมา `push` ลงคิว
ตามลำดับ จากนั้นอ่านจำนวน `m` แล้วเรียก `pop_back()` ซ้ำ `m` ครั้ง โดย `m`
อาจมากกว่าจำนวนสมาชิกที่มีก็ได้ แล้วพิมพ์

1. บรรทัดแรก: `size()` หลังการเรียก `pop_back` ทั้งหมด
2. บรรทัดที่สอง: หลังจาก `push(77)` และ `push(88)` ให้พิมพ์ `front()`,
   `back()` และ `size()` คั่นด้วยช่องว่าง
3. บรรทัดที่สาม: สมาชิกทั้งหมด โดยวนพิมพ์ `front()` แล้ว `pop()` จนคิวว่าง

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `pop_back` สลับกับ `push`, `pop`, `front`,
  `back` และ `size` หลายครั้ง
- เรียก `pop_back` ติดต่อกันจนคิวว่างและเรียกเกินไปอีกหลายครั้ง แล้วจึง
  `push` ของใหม่เข้าไปใช้งานต่อ
- สร้างคิวจากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::queue<int>`,
  `CP::queue<std::string>` และ `CP::queue<long long>`
- คัดลอกคิวด้วย copy constructor และ copy assignment แล้วตรวจว่าคิวต้นฉบับ
  ไม่เปลี่ยน

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
5
10 20 30 40 50
6
```

### ข้อมูลออก

```sample-output
0
77 88 2
77 88
```

คิวมีสมาชิก 5 ตัว แต่ถูกเรียก `pop_back()` ถึง 6 ครั้ง ห้าครั้งแรกเอาสมาชิก
ออกทีละตัวจนคิวว่าง ครั้งที่หกเป็นการเรียกกับคิวว่าง ซึ่งต้องไม่ทำอะไร จึง
ได้ `size()` เป็น `0` หลังจากนั้นคิวต้องยังใช้งานได้ `push(77)` และ
`push(88)` ทำให้คิวเป็น `77 88`

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
คิวว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` เข้าท้ายคิว |
| `pop` | นำสมาชิกตัวหน้าสุดออก (ถ้าคิวว่างจะข้ามคำสั่งนี้) |
| `pop_back` | เรียก `pop_back()` โดยไม่ตรวจก่อนว่าคิวว่างหรือไม่ |
| `front` | พิมพ์สมาชิกตัวหน้าสุด |
| `back` | พิมพ์สมาชิกตัวหลังสุด |
| `size` | พิมพ์จำนวนสมาชิก |
| `copy` | คัดลอกคิว แล้วพิมพ์ข้อมูลของสำเนา โดยคิวต้นฉบับต้องไม่เปลี่ยน |
| `digest` | พิมพ์ค่าสรุปที่คำนวณจากสมาชิกทุกตัวเรียงจากหน้าไปหลัง |

ให้สังเกตว่าคำสั่ง `pop_back` ของ grader **ไม่** ตรวจก่อนว่าคิวว่างหรือเปล่า
ต่างจากคำสั่ง `pop` ที่ grader ข้ามให้เมื่อคิวว่าง การรับมือกับคิวว่างจึง
เป็นหน้าที่ของฟังก์ชันที่คุณเขียน

คำสั่ง `digest` ทำงานบนสำเนาของคิว โดยอ่าน `front()` แล้ว `pop()` ไปเรื่อย ๆ
จนหมดคิว แล้วย่อลำดับทั้งหมดเป็นเลขตัวเดียว ถ้ามีสมาชิกตัวใดอยู่ผิดตำแหน่ง
หรือจำนวนสมาชิกเพี้ยนไป ค่านี้จะเปลี่ยนไปทันที

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากคิวทั้งหมดด้วย
`front` และ `pop` แล้วพิมพ์จำนวนสมาชิกพร้อมค่าสรุปของลำดับที่ได้

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกเริ่มต้น
`n ≤ 60,000` ตัว และมีคำสั่งไม่เกิน 155,000 คำสั่ง สมาชิกชนิดจำนวนเต็มมีค่า
สัมบูรณ์ไม่เกิน 10⁶ สำหรับ `int` และไม่เกิน 4 × 10⁹ สำหรับ `long long`
ส่วนสมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 6 ตัว
