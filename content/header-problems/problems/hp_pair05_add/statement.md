## คำอธิบาย

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
`T1 first` และ `T2 second`

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
CP::pair<T1, T2> CP::pair<T1, T2>::operator+(const CP::pair<T1, T2> &other) const;
```

ที่ บวกสมาชิกที่อยู่ตำแหน่งเดียวกันเข้าด้วยกัน แล้วคืนคู่อันดับใหม่ นั่นคือถ้า
`*this` เป็น `(a, b)` และ `other` เป็น `(c, d)` ผลลัพธ์ต้องเป็น
`(a + c, b + d)` โดยคู่อันดับทั้งสองที่นำมาบวกต้องไม่เปลี่ยนค่า

ความหมายของเครื่องหมาย `+` ขึ้นกับชนิดของสมาชิก ถ้าสมาชิกเป็นจำนวนเต็มก็เป็น
การบวกเลขตามปกติ แต่ถ้าสมาชิกเป็น `std::string` เครื่องหมาย `+` คือ
**การต่อข้อความ** ซึ่งไม่สลับที่ นั่นคือ `b + d` กับ `d + b` ให้ผลไม่เหมือนกัน
ดังนั้นลำดับของตัวตั้งและตัวบวกจึงสำคัญ ข้อนี้มีข้อมูลทดสอบที่สมาชิกเป็นข้อความ
ทั้งตำแหน่งที่หนึ่งและตำแหน่งที่สอง

ผลลัพธ์ต้องเป็นคู่อันดับที่คืนออกไปเป็นค่า (by value) ไม่ใช่การแก้ค่าใน `*this`
เพราะฟังก์ชันนี้เป็น `const` และผู้เรียกอาจนำผลที่ได้ไปบวกต่อทันที

คลาสนี้ยังมีฟังก์ชัน `plus_twice` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` โดยคิด
`*this + other + other` จึงนำผลของการบวกครั้งแรกไปบวกต่ออีกครั้ง และในไฟล์
`{{submission}}` มีฟังก์ชัน `doubled` ที่คืนผลของคู่อันดับบวกกับตัวมันเอง
ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมายเดิมไว้

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ `n` แล้วอ่านคู่อันดับชนิด
`CP::pair<int,std::string>` มา `n` คู่ สำหรับคู่ที่สองเป็นต้นไป โปรแกรมจะพิมพ์
ผลบวกของคู่นั้นกับคู่ก่อนหน้า หนึ่งบรรทัดต่อหนึ่งผลบวก จากนั้นบรรทัดสุดท้าย
พิมพ์ผลของ `doubled()` ของคู่แรก

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน ชุดคำสั่ง แล้วเรียก `+`, `doubled`, `plus_twice`, คอนสตรักเตอร์ และการ
  คัดลอกคู่อันดับสลับกันไปมา
- สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<long long,long long>`,
  `CP::pair<int,std::string>` และ `CP::pair<std::string,std::string>`
- บวกต่อกันหลายชั้นในนิพจน์เดียว เช่น `(A[i] + A[j]) + (A[j] + A[i])` ซึ่ง
  สำหรับข้อมูลชนิดข้อความจะให้ผลไม่เท่ากันทั้งสองวงเล็บ
- บวกกับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง ซึ่งเป็นค่าศูนย์ของจำนวนเต็ม และ
  เป็นข้อความว่างของ `std::string`

ดังนั้นถ้าคุณแก้ `doubled` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
3
2 ab
5 cd
-1 e
```

### ข้อมูลออก

```sample-output
7 abcd
4 cde
4 abab
```

บรรทัดแรกคือ `(2, "ab") + (5, "cd")` ได้ `(7, "abcd")` บรรทัดที่สองคือ
`(5, "cd") + (-1, "e")` ได้ `(4, "cde")` และบรรทัดสุดท้ายคือ `doubled()` ของ
คู่แรก ซึ่งเท่ากับ `(2, "ab") + (2, "ab")` ได้ `(4, "abab")`

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ `n` ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `add i j` | พิมพ์ผลของ `A[i] + A[j]` |
| `dbl i` | พิมพ์ผลของ `A[i].doubled()` |
| `twice i j` | พิมพ์ผลของ `A[i].plus_twice(A[j])` |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` แล้วพิมพ์ผลของ `A[i] + A[i]` |
| `zero i` | พิมพ์ผลของ `A[i]` บวกกับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |
| `chain i j` | พิมพ์ผลของ `(A[i] + A[j]) + (A[j] + A[i])` |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะวนบวกคู่อันดับที่อยู่ติดกันทุกตำแหน่งใน
อาเรย์ นำผลทั้งหมดมาคิดเป็นค่าตรวจสอบ (hash) หนึ่งค่า แล้วพิมพ์ออกมา จึงเป็น
การตรวจทั้งอาเรย์ ไม่ใช่แค่ตำแหน่งที่ถูกถามถึง

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมี `n ≤ 20,000` และ
มีคำสั่งไม่เกิน `q ≤ 30,000` คำสั่ง สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน
`10^8` สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน `10^12` และสมาชิกชนิด
ข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 6 ตัว ผลบวกที่ grader พิมพ์
ประกอบจากคู่อันดับไม่เกินสี่ตัว จึงไม่มีการล้นของจำนวนเต็ม
