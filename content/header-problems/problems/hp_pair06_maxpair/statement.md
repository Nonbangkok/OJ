# Pair Larger

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
<b>`T1 first`</b> และ <b>`T2 second`</b>

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T1, typename T2>
const CP::pair<T1, T2> &CP::pair<T1, T2>::larger(const CP::pair<T1, T2> &other) const;
```

ที่คืน <b>คู่อันดับที่มากกว่า</b> ระหว่าง `*this` กับ `other` โดยเทียบแบบพจนานุกรม
คือดู `first` ก่อน ถ้า `first` เท่ากันจึงดู `second` และกำหนดว่าถ้าคู่อันดับทั้ง
สองเท่ากันทุกตำแหน่ง ให้คืน `*this`

จุดสำคัญของข้อนี้อยู่ที่ชนิดของค่าที่คืน ซึ่งเป็น <b>การอ้างอิง</b> ไปยังคู่อันดับ
ไม่ใช่สำเนาของคู่อันดับ นั่นคือ ต้องคืนการอ้างอิงไปยังคู่อันดับตัวจริง ตัวใด
ตัวหนึ่งระหว่าง `*this` กับ `other` เท่านั้น การสร้างคู่อันดับใหม่หรือตัวแปร
ภายในฟังก์ชันแล้วคืนการอ้างอิงไปยังตัวนั้นถือว่าผิด เพราะตัวแปรภายในจะหมดอายุ
ทันทีที่ฟังก์ชันคืนค่า ผู้เรียกจะได้การอ้างอิงที่ชี้ไปยังหน่วยความจำที่ไม่มีค่า
นั้นอยู่แล้ว

ผู้เรียกใช้ความจริงข้อนี้ได้ ตัวอย่างเช่นคลาสนี้มีฟังก์ชัน `dominates` ซึ่ง
เขียนไว้ให้แล้วในไฟล์ `{{ds}}` และตอบว่า `*this` เป็นผู้ชนะหรือไม่ โดย
เปรียบเทียบ <b>ตำแหน่งในหน่วยความจำ</b> ที่การอ้างอิงชี้ไป กับตำแหน่งของตัวมันเอง
ถ้า `larger` คืนสำเนา ฟังก์ชันนี้จะตอบว่าไม่ชนะทั้งสองฝ่าย ซึ่งผิดทันที

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `larger3` ที่หาคู่ที่มากที่สุดจากสามคู่
โดยเรียก `larger` ต่อกันสองชั้น ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคง
ความหมายเดิมไว้

ชนิด `T1` และ `T2` รับประกันว่ามีตัวดำเนินการ `<` ของตัวเองอยู่แล้ว

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ $n$ แล้วอ่านคู่อันดับชนิด
`CP::pair<int,int>` มา $n$ คู่ คู่แรกถูกใช้เป็นคู่อ้างอิง สำหรับคู่ที่สอง
เป็นต้นไปโปรแกรมจะพิมพ์ผลของ `dominates` ทั้งสองทิศทางระหว่างคู่อ้างอิงกับคู่
นั้น และเก็บคู่ที่มากที่สุดไว้ด้วย `larger` จากนั้นบรรทัดสุดท้ายพิมพ์คู่ที่
มากที่สุด

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> แล้วเรียก `larger`, `larger3`, `dominates`, คอนสตรักเตอร์
  และการคัดลอกคู่อันดับสลับกันไปมา
* สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,int>`,
  `CP::pair<std::string,int>` และ `CP::pair<long long,long long>`
* พิมพ์ <b>ตัวบ่งชี้</b> ว่าการอ้างอิงที่ได้คืนมาชี้ไปที่ตัวใด เป็น `L` เมื่อชี้ไป
  ที่ตัวซ้าย `R` เมื่อชี้ไปที่ตัวขวา และ `X` เมื่อชี้ไปที่อื่น ซึ่งคำตอบที่ถูก
  จะไม่มี `X` เลย
* เทียบคู่อันดับกับตัวมันเอง และเทียบคู่ที่เท่ากันทุกตำแหน่ง ซึ่งต้องคืน
  การอ้างอิงไปที่ตัวซ้ายตามกฎข้างต้น

ดังนั้นถ้าคุณแก้ `larger3` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนคู่อันดับ<br>
$n$ บรรทัดถัดมา : บรรทัดที่ $i$ $(1 \leq i \leq n)$ รับจำนวนเต็ม $a_i$ และ
$b_i$ แทนสมาชิก `first` และ `second` ของคู่อันดับที่ $i$ โดยคู่อันดับที่ $1$
เป็นคู่อ้างอิง

## Output :

มีทั้งหมด $n$ บรรทัด โดย<br>
$n - 1$ บรรทัดแรก : บรรทัดที่ $i$ $(1 \leq i \leq n - 1)$ แสดงจำนวนเต็มสองจำนวน
คือผลของ `dominates` ของคู่อ้างอิงต่อคู่อันดับที่ $i + 1$ และผลของ `dominates`
ในทิศทางกลับกัน โดย `1` แทนจริงและ `0` แทนเท็จ<br>
บรรทัดสุดท้าย : แสดง `first` และ `second` ของคู่อันดับที่มากที่สุด

## Examples :

### ตัวอย่างที่ 1

```sample-input
4
3 7
3 9
1 100
3 7
```

```sample-output
0 1
1 0
1 1
3 9
```

## คำอธิบายตัวอย่างที่ 1

คู่อ้างอิงคือ $(3, 7)$ คู่ที่สอง $(3, 9)$ มี `first` เท่ากันแต่ `second` มากกว่า
จึงเป็นผู้ชนะ คู่ที่สาม $(1, 100)$ มี `first` น้อยกว่าจึงแพ้ แม้ `second` จะ
มากกว่า คู่ที่สี่เท่ากับคู่อ้างอิงพอดี ทั้งสองฝ่ายจึงชนะเมื่อเป็นตัวซ้ายของ
`larger` และคู่ที่มากที่สุดคือ $(3, 9)$

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ $n$ ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `max i j` | พิมพ์ค่าของ `A[i].larger(A[j])` และตัวบ่งชี้ว่าการอ้างอิงชี้ไปที่ตัวใด |
| `max3 i j k` | พิมพ์ค่าของ `A[i].larger3(A[j], A[k])` และตัวบ่งชี้ |
| `dom i j` | พิมพ์ผลของ `A[i].dominates(A[j])` และ `A[j].dominates(A[i])` |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` แล้วเทียบ `A[i]` กับตัวมันเอง |
| `self i` | เทียบ `A[i]` กับตัวมันเองและพิมพ์ตัวบ่งชี้ |
| `zero i` | เทียบ `A[i]` กับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะหาคู่ที่มากที่สุดของทั้งอาเรย์ โดยเลื่อน
ตำแหน่งผู้ชนะไปเมื่อการอ้างอิงที่ได้คืนมาชี้ไปที่ตัวใหม่เท่านั้น แล้วพิมพ์
ตำแหน่งและค่าของผู้ชนะ การคืนสำเนาจะทำให้ผู้ชนะไม่เคยเลื่อน และผลที่พิมพ์
ออกมาผิดทันที

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีคู่อันดับ $n \leq 20{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 30{,}000$ คำสั่ง
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^9$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
