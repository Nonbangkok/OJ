## คำอธิบาย

คลาส `CP::pair<T1,T2>` ในไฟล์ `{{ds}}` เก็บข้อมูลสองตัวไว้ในตัวแปรสมาชิก
`T1 first` และ `T2 second`

งานของคุณคือเขียนตัวดำเนินการเปรียบเทียบ **ทั้งหกตัว** ของคลาสนี้

```cpp
template <typename T1, typename T2>
bool CP::pair<T1, T2>::operator==(const CP::pair<T1, T2> &other) const;
// และ !=, <, <=, >, >= ในรูปแบบเดียวกัน
```

โดยใช้ลำดับแบบพจนานุกรม คือเทียบ `first` ก่อน ถ้า `first` เท่ากันจึงเทียบ
`second`

สิ่งที่ข้อนี้ตรวจไม่ใช่แค่ว่าแต่ละตัวตอบถูกแยกกัน แต่คือ ตัวดำเนินการทั้งหกตัว
ต้องให้คำตอบที่สอดคล้องกัน สำหรับคู่อันดับสองคู่ใด ๆ เสมอ นั่นคือต้องเป็นจริง
ทุกข้อ

- `a == b` เป็นจริงเมื่อ `a != b` เป็นเท็จ และกลับกัน
- `a < b` เป็นจริงเมื่อ `a >= b` เป็นเท็จ และกลับกัน
- `a > b` เป็นจริงเมื่อ `a <= b` เป็นเท็จ และกลับกัน
- `a <= b` เป็นจริงเมื่อ `a < b` หรือ `a == b` เป็นจริง
- `a >= b` เป็นจริงเมื่อ `a > b` หรือ `a == b` เป็นจริง
- จากสามความสัมพันธ์ `a < b`, `a == b`, `a > b` ต้องเป็นจริงเพียงข้อเดียวเท่านั้น

วิธีที่ปลอดภัยที่สุดคือเขียนตัวดำเนินการตัวเดียวให้ถูกต้องอย่างแท้จริง เช่น
`<` และ `==` แล้วนิยามอีกสี่ตัวจากสองตัวนั้น แทนการเขียนทั้งหกตัวแยกกัน
เพราะการเขียนแยกกันมีโอกาสที่ขอบของเครื่องหมายจะไม่ตรงกัน ซึ่งจะโผล่เฉพาะกับ
คู่อันดับที่เท่ากันหรือคู่ที่ `first` ตรงกัน

คลาสนี้มีฟังก์ชัน `compare_sign` ซึ่งเขียนไว้ให้แล้วในไฟล์ `{{ds}}` และคืนค่า
`-1`, `0` หรือ `1` โดยใช้ `<` ของคุณเพียงตัวเดียวสองครั้ง ถ้า `<` ของคุณคืน
`true` ให้ทั้งสองทิศทางของคู่หนึ่ง ฟังก์ชันนี้จะตอบ `-1` แม้ควรเป็น `0`

ในไฟล์ `{{submission}}` ยังมีฟังก์ชัน `clamp` ที่จำกัดค่าให้อยู่ในช่วงระหว่าง
ค่าขั้นต่ำกับค่าขั้นสูง และคืนการอ้างอิงไปยังคู่อันดับตัวใดตัวหนึ่งที่รับเข้ามา
ซึ่งเขียนไว้ถูกต้องแล้ว คุณแก้ได้แต่ต้องคงความหมายเดิมไว้

ชนิด `T1` และ `T2` รับประกันว่ามีตัวดำเนินการ `<` ของตัวเองอยู่แล้ว

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนคู่อันดับ `n` แล้วอ่านคู่อันดับชนิด
`CP::pair<int,int>` มา `n` คู่ คู่แรกถูกใช้เป็นคู่อ้างอิง สำหรับคู่ที่สอง
เป็นต้นไปโปรแกรมจะพิมพ์ผลของตัวดำเนินการทั้งหกตัวเทียบกับคู่อ้างอิง ตามลำดับ
`==`, `!=`, `<`, `<=`, `>`, `>=` เป็น `1` หรือ `0` หกค่าในหนึ่งบรรทัด จากนั้น
บรรทัดสุดท้ายพิมพ์ผลของ `compare_sign` ระหว่างคู่สุดท้ายกับคู่อ้างอิง

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน ชุดคำสั่ง แล้วเรียกตัวดำเนินการทั้งหกตัว รวมกับ `clamp`,
  `compare_sign`, คอนสตรักเตอร์ และการคัดลอกคู่อันดับสลับกันไปมา
- สร้างคู่อันดับจากชนิดข้อมูลสามแบบ คือ `CP::pair<int,int>`,
  `CP::pair<std::string,int>` และ `CP::pair<long long,long long>`
- ตรวจกฎความสอดคล้องทั้งหกข้อข้างต้นกับ **ทุกคู่ที่เป็นไปได้** ภายในช่วงสั้น ๆ
  ที่สุ่มเลือกมา แล้วรายงานจำนวนครั้งที่กฎถูกละเมิด ซึ่งคำตอบที่ถูกต้องต้อง
  เป็นศูนย์ทุกครั้ง
- เทียบคู่อันดับกับตัวมันเอง ซึ่งต้องได้ `1 0 0 1 0 1` เสมอ
- นำ `<` ไปใช้เป็นตัวเปรียบเทียบของ merge sort แบบ stable กับอาเรย์ทั้งชุด
  เมื่อจบบล็อก

ดังนั้นถ้าคุณแก้ `clamp` แล้วทำให้พฤติกรรมเดิมของฟังก์ชันนั้นเสียไป
ระบบจะจับได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
3
4 4
4 9
4 4
```

### ข้อมูลออก

```sample-output
0 1 0 0 1 1
1 0 0 1 0 1
0
```

คู่อ้างอิงคือ `(4, 4)` คู่ที่สอง `(4, 9)` มี `first` เท่ากันแต่ `second` มากกว่า
จึงมากกว่าคู่อ้างอิง ได้ `== 0`, `!= 1`, `< 0`, `<= 0`, `> 1` และ `>= 1` คู่ที่
สามเท่ากับคู่อ้างอิงทุกตำแหน่ง จึงได้ `== 1`, `!= 0`, `< 0`, `<= 1`, `> 0` และ
`>= 1` ซึ่งเป็นรูปแบบเดียวที่ถูกต้องสำหรับคู่ที่เท่ากัน และ `compare_sign`
ระหว่างคู่สุดท้ายกับคู่อ้างอิงจึงเป็น `0`

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกระบุชนิด
ข้อมูลของตัวเอง แล้วสร้างอาเรย์ของคู่อันดับ `n` ตัว หลังจากนั้นจะมีคำสั่งผสมกัน
ดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `six i j` | พิมพ์ผลของตัวดำเนินการทั้งหกตัวระหว่าง `A[i]` กับ `A[j]` |
| `laws l len` | ตรวจกฎความสอดคล้องกับทุกคู่ภายในช่วง แล้วพิมพ์จำนวนการละเมิดและค่าตรวจสอบ |
| `clamp i j k` | พิมพ์ผลของ `A[i].clamp(A[j], A[k])` และตัวบ่งชี้ว่าการอ้างอิงชี้ไปที่ตัวใด |
| `assign i a b` | ทำ `A[i] = CP::pair(a, b)` ด้วยการคัดลอก |
| `self i` | เทียบ `A[i]` กับตัวมันเอง |
| `zero i` | เทียบ `A[i]` กับคู่อันดับที่สร้างจากคอนสตรักเตอร์ว่าง |
| `sign i j` | พิมพ์ `compare_sign` ทั้งสองทิศทาง ซึ่งต้องเป็นค่าตรงข้ามกันเสมอ |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะวนตรวจกฎทั้งหกข้อกับคู่ที่อยู่ติดกันทั้ง
อาเรย์ นำรหัสหกบิตของทุกคู่มาคิดเป็นค่าตรวจสอบ (hash) แล้วเรียงอาเรย์ทั้งชุด
ด้วย merge sort แบบ stable ที่ใช้ `<` และพิมพ์ค่าตรวจสอบของผลเรียงด้วย

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมี `n ≤ 20,000` และ
มีคำสั่งไม่เกิน `q ≤ 30,000` คำสั่ง ความยาวของช่วงในคำสั่ง `laws` ไม่เกิน 24
สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน `10^9` สมาชิกชนิด `long long` มีค่า
สัมบูรณ์ไม่เกิน `4 × 10^9` และสมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็ก
ยาวไม่เกิน 6 ตัว
