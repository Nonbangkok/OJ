## คำอธิบาย

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บสมาชิก `mSize` ตัวเรียงติดกันใน
อาเรย์ `mData` ที่จองไว้ `mCap` ช่อง และมีฟังก์ชันช่วยแบบ `protected` สอง
ตัวสำหรับจัดการที่ว่าง

- `expand(capacity)` — จองอาเรย์ใหม่ขนาด `capacity` ช่อง คัดลอกสมาชิกเดิม
  ทั้งหมดไปใส่ แล้วทิ้งอาเรย์เก่า ใช้เวลา O(n) **ทุกครั้งที่เรียก**
- `ensureCapacity(capacity)` — ถ้าที่ที่มีอยู่พอแล้วจะไม่ทำอะไรเลย ถ้าไม่พอ
  จะเรียก `expand` ด้วยขนาด `max(capacity, 2 × mCap)` นั่นคือ **ขยายเป็น
  เท่าตัว**

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::insert(size_t pos, const T &value);
```

ที่แทรกค่าใหม่เข้าไปก่อนตำแหน่ง `pos` โดย

1. สมาชิกตั้งแต่ตำแหน่ง `pos` เดิมขึ้นไปต้องเลื่อนไปทางขวาหนึ่งช่อง และ
   `size()` เพิ่มขึ้นหนึ่ง
2. `pos == size()` หมายถึงการเพิ่มที่ท้ายเวกเตอร์ (append) ซึ่งเป็นค่าที่
   ถูกต้อง ส่วน `pos > size()` ให้ **ไม่ทำอะไรเลย**
3. ถ้าที่ในอาเรย์ไม่พอต้องขยายก่อน และนี่คือหัวใจของข้อนี้: **การแทรกที่ท้าย
   เวกเตอร์ติดต่อกัน q ครั้งต้องใช้เวลารวม O(q)** (เฉลี่ยครั้งละ O(1))
   การเรียก `expand(mSize + 1)` ทุกครั้งให้คำตอบที่ถูกต้องเหมือนกัน แต่
   คัดลอกข้อมูลทั้งเวกเตอร์ใหม่ทุกครั้ง เวลารวมจึงกลายเป็น O(q²) และจะไม่ทัน
   ในชุดทดสอบใหญ่
4. การแทรกที่ตำแหน่งอื่นใช้เวลา O(n − pos) ตามจำนวนสมาชิกที่ต้องเลื่อน ซึ่ง
   เลี่ยงไม่ได้

เวกเตอร์จะจองที่ไว้มากกว่าที่ใช้จริงเท่าไรเป็นเรื่องของคุณ ระบบตรวจ
**ไม่ตรวจค่า `capacity()`** แต่ตรวจ `size()`, ลำดับของสมาชิก และเวลาที่ใช้

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่าน `n` แล้วนำสมาชิก `n` ตัวเข้าเวกเตอร์ด้วย
`v.insert(v.size(), element)` จากนั้นอ่านจำนวนคำสั่ง `q` แล้วอ่านคู่
`pos value` อีก `q` คู่ และเรียก `v.insert(pos, value)` ตามลำดับ แล้วพิมพ์

1. บรรทัดแรก: `size()`
2. บรรทัดที่สอง: สมาชิกทั้งหมดตามลำดับ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `insert` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
- มีคำสั่งที่สั่งแทรกที่ท้ายเวกเตอร์เป็นชุดใหญ่ถึงหนึ่งล้านครั้งในคำสั่งเดียว
  ซึ่งเป็นชุดทดสอบที่แยกวิธีขยายแบบเท่าตัวออกจากวิธีขยายทีละช่อง
- แทรกที่ตำแหน่ง 0, `size() - 1`, `size()` และตำแหน่งที่เลย `size()` ออกไป
  เพื่อตรวจทั้งการเลื่อนข้อมูลและกรณีที่ต้องไม่ทำอะไร
- คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การแทรกผิดตำแหน่งหรือเลื่อนข้อมูล
  ทับกันจึงหลบไม่ได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
3
10 20 30
3
0 99
2 77
9 55
```

### ข้อมูลออก

```sample-output
5
99 10 77 20 30
```

เริ่มจาก `10 20 30` คำสั่ง `insert(0, 99)` ได้ `99 10 20 30` ต่อด้วย
`insert(2, 77)` ได้ `99 10 77 20 30` ส่วน `insert(9, 55)` มีตำแหน่งมากกว่า
`size()` ซึ่งขณะนั้นเท่ากับ 5 จึงไม่ทำอะไรเลย

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ล้างเวกเตอร์แล้วแทรกสมาชิก `n` ตัวที่สุ่มจาก `seed` ไว้ที่ท้ายเวกเตอร์ |
| `2 pos x` | เรียก `insert(pos, x)` แล้วพิมพ์ขนาดใหม่ |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วแทรกเพิ่มบนสำเนา โดยเวกเตอร์ต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10 k seed` | แทรก `k` ตัวที่ท้ายเวกเตอร์ด้วย `insert(size(), x)` |
| `11 k seed` | แทรก `k` ตัวที่ตำแหน่ง 0 |
| `12 k seed` | แทรก `k` ตัวที่ตำแหน่งกระจายทั่วเวกเตอร์ |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน ส่วนค่า `pos`
ของคำสั่ง `2` **ไม่ถูกปรับ** เพราะตำแหน่งที่เลยขอบเขตเป็นส่วนหนึ่งของสิ่งที่
ตรวจ เมื่อจบบล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกรวมไม่เกิน
ประมาณ 1,500,000 ตัว สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน 10⁶ ชนิด
`long long` ไม่เกิน 2 × 10⁹ และชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาว
ไม่เกิน 5 ตัว
