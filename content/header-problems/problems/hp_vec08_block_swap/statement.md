# Vector Block Swap

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บสมาชิก `mSize` ตัวเรียงติดกันใน
อาเรย์ `mData` ทำให้อ่านและเขียนสมาชิกตำแหน่งใดก็ได้โดยตรงในเวลาคงที่

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::block_swap(size_t i, size_t j, size_t len);
```

ที่สลับข้อมูลสองช่วงที่ยาวเท่ากัน คือช่วง `[i, i + len)` กับช่วง
`[j, j + len)` โดยสมาชิกตัวที่ `i + k` ไปอยู่ตำแหน่ง `j + k` และตัวที่
`j + k` มาอยู่ตำแหน่ง `i + k` สำหรับทุก $k$ ตั้งแต่ $0$ ถึง $len - 1$

คำสั่งจะถือว่า <b>ใช้ไม่ได้</b> และต้อง <b>ไม่ทำอะไรเลย</b> ในกรณีต่อไปนี้

1. `len == 0`
2. ช่วงใดช่วงหนึ่งล้นออกไปนอกเวกเตอร์ คือ `i + len > size()` หรือ
   `j + len > size()` (รวมถึงกรณี `len > size()`)
3. สองช่วง <b>ซ้อนทับกัน</b> ซึ่งรวมกรณี `i == j` ด้วย

ข้อควรระวังสองเรื่อง

* `size_t` ไม่มีค่าติดลบและมีค่าสูงสุดจำกัด การเขียนเงื่อนไขเป็น
  `i + len > mSize` อาจ <b>ล้น (overflow)</b> เมื่อ `len` มีค่ามหาศาล จนเงื่อนไข
  กลายเป็นจริงผิด ๆ ทางที่ปลอดภัยคือตรวจ `len > mSize` ก่อน แล้วค่อยตรวจ
  `i > mSize - len`
* การตรวจการซ้อนทับเขียนได้สั้น ๆ ด้วย `lo = min(i, j)` และ `hi = max(i, j)`
  สองช่วงแยกกันสนิทเมื่อ `hi - lo >= len` เท่านั้น

เงื่อนไขเรื่องเวลา: <b>ต้องใช้เวลา $O(len)$</b> ต่อการเรียกหนึ่งครั้ง และใช้
หน่วยความจำเพิ่มเพียงค่าคงที่ (ตัวแปรชั่วคราวหนึ่งตัวสำหรับการสลับ)
การคัดลอกเวกเตอร์ทั้งใบไว้เป็นสำเนาก่อนแล้วค่อยเขียนกลับ ให้คำตอบถูกเหมือนกัน
แต่ใช้เวลา $O(n)$ ต่อครั้ง และจะไม่ทันเมื่อถูกเรียกสองหมื่นครั้งบนเวกเตอร์ขนาด
หนึ่งล้าน

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่าน $n$ และสมาชิก $n$ ตัวลงใน `CP::vector<int>` จากนั้น
อ่านจำนวนคำสั่ง $q$ แล้วอ่านชุดตัวเลข $i, j, len$ อีก $q$ ชุด เรียก
`block_swap` ตามลำดับ แล้วพิมพ์สมาชิกทั้งหมดในบรรทัดเดียว

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `block_swap` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์
* สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
* มีคำสั่งที่ <b>สร้างคู่ช่วงที่ถูกต้องขึ้นเองภายในโปรแกรม</b> แล้วสลับซ้ำได้ถึง
  สองหมื่นครั้งในคำสั่งเดียว โดย `len` สั้นมาก ซึ่งเป็นชุดที่แยกวิธี $O(len)$
  ออกจากวิธีที่แตะข้อมูลทั้งเวกเตอร์
* ยิงค่าที่ใช้ไม่ได้ทุกแบบ: `len == 0`, `i == j`, ช่วงซ้อนทับกัน, ช่วงล้น
  ท้ายเวกเตอร์ และ `len` มากกว่า `size()` ทั้งหมดต้องไม่เปลี่ยนข้อมูลเลย
* สลับครึ่งหน้ากับครึ่งหลังทั้งเวกเตอร์ ซึ่งเป็น `len` ที่ใหญ่ที่สุดที่ทำได้
* คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การคัดลอกช่วงหนึ่งไปทับอีกช่วงแทน
  การสลับจึงหลบไม่ได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกของเวกเตอร์<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ แทนสมาชิก
ของเวกเตอร์<br>
บรรทัดที่สาม : รับจำนวนเต็ม $q$ แทนจำนวนคำสั่ง `block_swap`<br>
$q$ บรรทัดถัดมา : แต่ละบรรทัดรับจำนวนเต็มสามจำนวน คือ $i$, $j$ และ $len$

## Output :

มีทั้งหมด $1$ บรรทัด แสดงสมาชิกทั้งหมดของเวกเตอร์ตามลำดับหลังทำคำสั่งครบ
ทั้ง $q$ คำสั่ง

## Examples :

### ตัวอย่างที่ 1

```sample-input
8
10 20 30 40 50 60 70 80
2
1 5 3
0 2 3
```

```sample-output
10 60 70 80 50 20 30 40
```

## คำอธิบายตัวอย่างที่ 1

คำสั่งแรกสลับช่วง $[1, 4)$ ซึ่งคือ $20, 30, 40$ กับช่วง $[5, 8)$ ซึ่งคือ
$60, 70, 80$ ผลลัพธ์จึงเป็น $10, 60, 70, 80, 50, 20, 30, 40$ คำสั่งที่สองคือ
`block_swap(0, 2, 3)` ซึ่งช่วง $[0, 3)$ กับ $[2, 5)$ ซ้อนทับกัน จึงไม่ทำ
อะไรเลย

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` |
| `2 i j len` | เรียก `block_swap(i, j, len)` ด้วยค่าที่ให้มาตรง ๆ |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4` | สลับครึ่งหน้ากับครึ่งหลังของเวกเตอร์ |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วสลับช่วงบนสำเนา โดยต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10 count seed maxlen` | สร้างคู่ช่วงที่ถูกต้อง `count` คู่จาก `seed` โดย `len ≤ maxlen` แล้วสลับทั้งหมด |

ค่า `i`, `j`, `len` ของคำสั่ง `2` <b>ไม่ถูกปรับ</b> เพราะค่าที่ใช้ไม่ได้เป็น
ส่วนหนึ่งของสิ่งที่ตรวจ ส่วนดัชนีของคำสั่ง `3` จะถูกปรับด้วย `i % size()`
เมื่อจบบล็อก grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกไม่เกิน $1{,}000{,}000$ ตัว
* ค่า $len$ ไม่เกินประมาณ $size() + 10$
* จำนวนการสลับที่สร้างขึ้นไม่เกิน $20{,}000$ ครั้งต่อคำสั่ง
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^6$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $2 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $5$ ตัว
