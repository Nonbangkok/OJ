# Stack Swap Top

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก และสมาชิกตัวบนสุดของสแตกอยู่ที่
`mData[mSize - 1]` ฟังก์ชัน `push`, `pop` และ `top` เขียนไว้ให้แล้วในไฟล์
`{{ds}}`

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::stack<T>::swap_top();
```

ที่ <b>สลับที่สมาชิกสองตัวบนสุดของสแตก</b> ให้ตัวที่อยู่ใต้ตัวบนสุดขึ้นมาเป็น
ตัวบนสุด และตัวบนสุดเดิมลงไปอยู่ใต้ โดยสมาชิกตัวอื่นต้องอยู่ที่เดิมทั้งหมด
และต้องใช้เวลา <b>$O(1)$</b>

ข้อกำหนดและกับดัก

* ถ้าสแตกมีสมาชิกน้อยกว่า $2$ ตัว (ว่าง หรือมีตัวเดียว) ให้ <b>ไม่ทำอะไรเลย</b>
  ระวังว่า `mSize` เป็น `size_t` ซึ่งไม่มีเครื่องหมาย ดังนั้นเมื่อ
  `mSize` เป็น $1$ ค่า `mSize - 2` ไม่ใช่ $-1$ แต่เป็นจำนวนมหาศาล การเข้าถึง
  `mData` ด้วยดัชนีนั้นคือการเขียนทับหน่วยความจำนอกอาเรย์
* การสลับต้องใช้ตัวแปรชั่วคราวชนิด `T` เพราะ `T` ไม่จำเป็นต้องเป็นตัวเลข
  (ข้อมูลทดสอบมีทั้ง `int`, `long long` และ `std::string`) วิธีสลับด้วยการ
  บวกลบจึงใช้ไม่ได้
* เรียก `swap_top()` สองครั้งติดกันต้องได้สแตกกลับมาเหมือนเดิมทุกตัว
  ข้อมูลทดสอบมีคำสั่งที่เรียกสองครั้งติดกันแล้วตรวจว่าตัวบนสุดคือตัวเดิม

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก $n$ แล้วอ่านสมาชิก $n$ ตัวมา `push` ลง
สแตกตามลำดับ จากนั้นพิมพ์ค่าจาก `top()` แล้วเรียก `swap_top()` หนึ่งครั้งและ
พิมพ์ `top()` อีกครั้ง แล้วเรียก `pop()` หนึ่งครั้งและพิมพ์ `top()` กับ `size()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `swap_top()` สลับกับ `push`, `pop`, `top`,
  `size` หลายครั้ง รวมถึงเรียกตอนที่สแตกว่างและตอนที่มีสมาชิกตัวเดียว
* มีคำสั่งที่เรียก `swap_top()` สองครั้งติดกันแล้วพิมพ์ตัวบนสุด
* คัดลอกสแตกแล้ว `pop` สำเนาหนึ่งครั้ง เพื่ออ่าน <b>ทั้งสองตัว</b> ที่ถูกสลับ
  โดยไม่แตะสแตกต้นฉบับ
* สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push` ลงสแตก<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push` ลงสแตก

## Output :

มีทั้งหมด $3$ บรรทัด โดย<br>
บรรทัดแรก : แสดงค่าจาก `top()`<br>
บรรทัดที่สอง : แสดงค่าจาก `top()` หลังเรียก `swap_top()` หนึ่งครั้ง<br>
บรรทัดที่สาม : แสดงค่าจาก `top()` และ `size()` หลังเรียก `pop()` อีกหนึ่งครั้ง
คั่นด้วยช่องว่าง

## Examples :

### ตัวอย่างที่ 1

```sample-input
5
10 20 30 40 50
```

```sample-output
50
40
50 4
```

## คำอธิบายตัวอย่างที่ 1

สแตกจากล่างขึ้นบนคือ $10, 20, 30, 40, 50$ ตัวบนสุดจึงเป็น $50$ หลัง
`swap_top()` สแตกกลายเป็น $10, 20, 30, 50, 40$ ตัวบนสุดเป็น $40$ เมื่อ `pop()`
ออกไปหนึ่งตัว ตัวบนสุดจึงเป็น $50$ และเหลือสมาชิก $4$ ตัว

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด หรือ `-` ถ้าสแตกว่าง |
| `size` | พิมพ์จำนวนสมาชิก |
| `swap` | เรียก `swap_top()` |
| `copy` | คัดลอกสแตก แล้วพิมพ์สองตัวบนสุดของสำเนา โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold` | เรียก `top()` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |
| `twice` | เรียก `swap_top()` สองครั้ง แล้วพิมพ์ตัวบนสุด ซึ่งต้องเป็นตัวเดิม |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากสแตกทั้งหมด แล้ว
พิมพ์สมาชิก $100$ ตัวแรกที่นำออก ตามด้วยค่า hash ของสมาชิกทุกตัวที่เคยถูกอ่าน
จึงเป็นการตรวจว่าการสลับไม่ได้ทำให้สมาชิกตัวอื่นเพี้ยนไปด้วย

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกเริ่มต้น $n \leq 50{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 120{,}000$ คำสั่ง
* สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
