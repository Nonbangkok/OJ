# Vector Compress

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บสมาชิก `mSize` ตัวเรียงติดกันใน
`mData[0]` ถึง `mData[mSize - 1]` ของอาเรย์ที่จองไว้ `mCap` ช่อง ข้อมูลที่มี
ค่าซ้ำกันอยู่ติดกันเป็นช่วง ๆ (run) เปลืองที่โดยไม่จำเป็น และการลบออกต้อง
ทำอย่างระมัดระวังเพื่อไม่ให้สมาชิกถูกเลื่อนซ้ำหลายรอบ

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::compress();
```

ที่ยุบสมาชิกซ้ำ <b>ที่อยู่ติดกัน</b> ให้เหลือไว้เพียงตัวแรกของแต่ละช่วงที่ซ้ำกัน
พูดอีกอย่างคือ ลบสมาชิกตำแหน่งที่ `i` ทุกตัวที่ `v[i] == v[i - 1]` ออก โดย

1. เปรียบเทียบด้วย `operator==` ของชนิด `T` เอง และเทียบกับ
   <b>เพื่อนบ้านทางซ้าย</b> เท่านั้น สมาชิกที่มีค่าเท่ากันแต่ไม่ได้อยู่ติดกัน
   <b>ต้องอยู่ครบ</b> เช่น $1, 1, 2, 2, 1$ ต้องกลายเป็น $1, 2, 1$ ไม่ใช่ $1, 2$
2. สมาชิกที่เหลือต้องเรียงตามลำดับเดิมและเริ่มที่ `mData[0]` ตามเดิม
   `size()` ลดลงเท่ากับจำนวนที่ลบ และ `capacity()` ไม่เปลี่ยน
3. เวกเตอร์ว่างและเวกเตอร์ที่มีสมาชิกตัวเดียวต้องไม่เปลี่ยนแปลง
4. ฟังก์ชันนี้ต้อง <b>idempotent</b> คือเรียกซ้ำอีกครั้งต้องไม่เปลี่ยนอะไร
   (เพราะหลังเรียกครั้งแรกไม่มีสมาชิกซ้ำติดกันเหลืออยู่แล้ว)
5. <b>ต้องใช้เวลา $O(n)$ และใช้หน่วยความจำเพิ่มคงที่ $O(1)$</b> คือเดินผ่าน
   เวกเตอร์เพียงพาสเดียว ห้ามจองอาเรย์ใหม่มาเก็บผลลัพธ์

ข้อ 5 เป็นหัวใจของโจทย์ วิธีที่คิดง่ายที่สุด — "วนหาคู่ที่ซ้ำกัน ลบทีละตัว
แล้วเลื่อนข้อมูลที่เหลือ" — ให้คำตอบถูกต้อง แต่เสียเวลา $O(n)$ ต่อสมาชิกที่ลบ
หนึ่งตัว ถ้าข้อมูลสามในสี่เป็นตัวซ้ำ เวลารวมจะเป็น $O(n^2)$ ซึ่งไม่ทันเมื่อ
$n$ เท่ากับหนึ่งล้าน แนวคิดที่ใช้ได้คือใช้ดัชนีสองตัว ตัวหนึ่งสำหรับ
"ตำแหน่งที่กำลังอ่าน" และอีกตัวสำหรับ "จำนวนตัวที่เก็บไว้แล้ว" ซึ่งทำให้
สมาชิกแต่ละตัวขยับไม่เกินหนึ่งครั้ง

ฟังก์ชัน `push_back` เตรียมไว้ให้แล้วในไฟล์ `{{ds}}` คุณไม่ต้องเขียนเอง

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่าน $n$ แล้ว `push_back` สมาชิก $n$ ตัวลงใน
`CP::vector<int>` เรียก `compress()` หนึ่งครั้ง แล้วพิมพ์ `size()` ที่เหลือ
ตามด้วยสมาชิกที่เหลือทั้งหมดตามลำดับ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `compress` สลับกับ `push_back`, `resize`,
  `clear`, `operator[]` และการคัดลอกเวกเตอร์
* สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>` การเปรียบเทียบจึงต้อง
  ใช้ `operator==` ของชนิดนั้นจริง ๆ
* <b>สร้างข้อมูลเป็นช่วง ๆ ขึ้นเองภายในโปรแกรม</b> จาก seed และความยาวช่วง
  เฉลี่ยที่กำหนด ดังนั้นคำสั่งบรรทัดเดียวสร้างข้อมูลได้ถึงหนึ่งล้านตัว โดย
  ครอบคลุมทั้งกรณี <b>ทุกตัวเท่ากันหมด</b> และกรณี <b>แทบไม่มีตัวซ้ำเลย</b>
* ใช้ค่าของสมาชิกจากชุดค่าที่แคบ (ไม่กี่ค่า) ทำให้มีช่วงที่อยู่คนละที่แต่ค่า
  เท่ากันบ่อย ๆ ซึ่งเป็นกรณีที่โปรแกรมที่ลบ "ทุกค่าที่ซ้ำ" (ไม่ใช่เฉพาะที่
  ติดกัน) จะตอบผิด
* มีคำสั่งที่เรียก `compress()` <b>สองครั้งติดกัน</b> แล้วพิมพ์ผลทั้งสองครั้ง
  เพื่อตรวจว่าครั้งที่สองไม่เปลี่ยนอะไร
* เรียก `resize` ขึ้น ซึ่งคลาสจะเติมช่องใหม่ด้วย `T()` เกิดเป็นช่วงของค่าที่
  เท่ากันต่อท้ายให้ยุบ
* คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การเก็บตัวซ้ำไว้เกินหรือลบตัวที่ไม่
  ควรลบจึงหลบไม่ได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push_back`<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push_back`

## Output :

มีทั้งหมด $2$ บรรทัด โดย<br>
บรรทัดแรก : แสดง `size()` ที่เหลือหลังเรียก `compress()`<br>
บรรทัดที่สอง : แสดงสมาชิกที่เหลือทั้งหมดตามลำดับ

## Examples :

### ตัวอย่างที่ 1

```sample-input
10
1 1 2 2 2 3 1 1 4 4
```

```sample-output
5
1 2 3 1 4
```

## คำอธิบายตัวอย่างที่ 1

ช่วง $1, 1$ ยุบเป็น $1$ ช่วง $2, 2, 2$ ยุบเป็น $2$ แล้ว $3$ อยู่ตัวเดียว ส่วน
$1, 1$ ที่ตามมายุบเป็น $1$ ซึ่ง <b>ไม่ถูกลบ</b> แม้ค่า $1$ จะปรากฏมาก่อนแล้ว
เพราะไม่ได้อยู่ติดกับช่วงแรก และปิดท้ายด้วย $4, 4$ ที่ยุบเป็น $4$

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed runlen` | สร้างข้อมูลใหม่ `n` ตัว เป็นช่วงที่ค่าเท่ากันยาวประมาณ `runlen` ตัว |
| `2` | เรียก `compress()` แล้วพิมพ์ขนาดใหม่ |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4 k x` | `push_back` ค่า `x` ซ้ำ `k` ครั้ง (เกิดช่วงซ้ำต่อท้าย) |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ ต่อท้ายสำเนาด้วยค่าซ้ำ แล้ว `compress` สำเนา โดยต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10` | เรียก `compress()` สองครั้ง แล้วพิมพ์ขนาดกับค่าสรุปของทั้งสองครั้ง |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน และถ้าเวกเตอร์
ว่างอยู่คำสั่ง `3` จะพิมพ์เครื่องหมาย `-` เมื่อจบบล็อก grader จะพิมพ์ขนาด
และค่าสรุปสุดท้ายของบล็อกนั้น

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกไม่เกินประมาณ $1{,}300{,}000$ ตัว
* สมาชิกชนิด `int` มีค่าตั้งแต่ $-3$ ถึง $3$
* สมาชิกชนิด `long long` มีค่าตั้งแต่ $-4$ ถึง $4$
* สมาชิกชนิดข้อความเป็นคำสั้น ๆ จากชุดคำ $6$ คำ
