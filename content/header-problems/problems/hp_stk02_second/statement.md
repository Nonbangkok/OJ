# Stack Second

คลาส `CP::stack<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ `mData` ที่จองไว้
`mCap` ช่อง โดยใช้งานจริง `mSize` ช่องแรก สมาชิกตัวที่ใส่เข้ามาก่อนอยู่ที่
ดัชนีน้อย และสมาชิกตัวบนสุดของสแตกอยู่ที่ช่องท้ายสุดที่กำลังใช้งาน
ฟังก์ชัน `push`, `pop` และ `top` เขียนไว้ให้แล้วในไฟล์ `{{ds}}`

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
const T &CP::stack<T>::second() const;
```

ที่ <b>คืนค่าสมาชิกที่อยู่ใต้ตัวบนสุด</b> นั่นคือสมาชิกที่จะกลายเป็นตัวบนสุดถ้า
เรียก `pop()` อีกหนึ่งครั้ง โดยใช้เวลา <b>$O(1)$</b> และคืนค่าเป็นการอ้างอิง
(reference) ไปยังสมาชิกตัวนั้นในอาเรย์ ไม่ใช่สำเนา

ข้อควรระวัง

* ฟังก์ชันนี้เป็น `const` จึงห้ามแก้ไขตัวแปรสมาชิกใด ๆ โดยเฉพาะ <b>ห้าม</b>
  เขียนเป็น "pop แล้ว top แล้ว push กลับ" เพราะจะเปลี่ยนสถานะของสแตก
* `second()` ต้องไม่ใช่ค่าเดียวกับ `top()` (ยกเว้นกรณีที่สมาชิกสองตัวบนสุด
  มีค่าเท่ากันอยู่แล้ว)
* โปรแกรมของผู้ออกข้อสอบจะเรียก `second()` เฉพาะเมื่อสแตกมีสมาชิกตั้งแต่
  $2$ ตัวขึ้นไป (ตรวจด้วย `size()` ก่อน) คุณจึงไม่ต้องจัดการกรณีที่สมาชิก
  น้อยกว่านั้น

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก $n$ แล้วอ่านสมาชิก $n$ ตัวมา `push` ลง
สแตกตามลำดับ จากนั้นพิมพ์ค่าจาก `top()` และ `second()` แล้วพิมพ์ค่าทั้งสอง
นั้นอีกครั้งหลังเรียก `pop()` หนึ่งครั้ง และพิมพ์จำนวนสมาชิกที่เหลือจาก `size()`

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `second()` สลับกับ `push`, `pop`, `top`,
  `size` หลายครั้ง โดยเฉพาะเรียกทันทีหลัง `pop` ซึ่งเป็นจุดที่ดัชนีผิดไปหนึ่งช่อง
  จะแสดงตัว
* สร้างสแตกจากชนิดข้อมูลมากกว่าหนึ่งชนิด เช่น `CP::stack<int>`,
  `CP::stack<std::string>` และ `CP::stack<long long>`
* คัดลอกสแตกด้วย copy constructor และ copy assignment แล้วตรวจว่าสแตกต้นฉบับ
  ไม่เปลี่ยน

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกที่จะ `push` ลงสแตก<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ ตามลำดับที่
`push` ลงสแตก

## Output :

มีทั้งหมด $3$ บรรทัด โดย<br>
บรรทัดแรก : แสดงค่าจาก `top()` และ `second()` คั่นด้วยช่องว่าง<br>
บรรทัดที่สอง : แสดงค่าทั้งสองนั้นอีกครั้ง หลังเรียก `pop()` หนึ่งครั้ง<br>
บรรทัดที่สาม : แสดงจำนวนสมาชิกที่เหลือจาก `size()`

## Examples :

### ตัวอย่างที่ 1

```sample-input
5
10 20 30 40 50
```

```sample-output
50 40
40 30
4
```

## คำอธิบายตัวอย่างที่ 1

ตอนแรกตัวบนสุดคือ $50$ และตัวที่อยู่ใต้ตัวบนสุดคือ $40$ หลัง `pop()` หนึ่ง
ครั้ง ค่าทั้งสองจึงเลื่อนลงมาเป็น $40$ และ $30$ และเหลือสมาชิก $4$ ตัว

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
สแตกว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `push x` | ใส่ `x` ลงบนสแตก |
| `pop` | นำสมาชิกตัวบนสุดออก (ถ้าสแตกว่างจะข้ามคำสั่งนี้) |
| `top` | พิมพ์สมาชิกตัวบนสุด |
| `second` | พิมพ์สมาชิกที่อยู่ใต้ตัวบนสุด หรือ `-` ถ้ามีสมาชิกน้อยกว่า $2$ ตัว |
| `size` | พิมพ์จำนวนสมาชิก |
| `copy` | คัดลอกสแตก แล้วพิมพ์ `size`, `top`, `second` ของสำเนา โดยสแตกต้นฉบับต้องไม่เปลี่ยน |
| `fold` | เรียก `second()` แล้วนำค่าไปรวมใน hash ของบล็อก (ไม่พิมพ์อะไร) |

เมื่อหมดคำสั่งของบล็อกหนึ่ง grader จะนำสมาชิกที่เหลือออกจากสแตกทั้งหมด แล้ว
พิมพ์สมาชิก $100$ ตัวแรกที่นำออก ตามด้วยค่า hash ของสมาชิกทุกตัวที่เคยถูกอ่าน
จึงเป็นการตรวจลำดับทั้งสแตก ไม่ใช่แค่สองตัวบนสุด

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกเริ่มต้น $n \leq 50{,}000$ ตัว
* แต่ละบล็อกมีคำสั่งไม่เกิน $q \leq 120{,}000$ คำสั่ง
* สมาชิกชนิดจำนวนเต็มมีค่าสัมบูรณ์ไม่เกิน $4 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $6$ ตัว
