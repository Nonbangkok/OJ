## คำอธิบาย

คลาส `CP::vector<T>` ในไฟล์ `{{ds}}` เก็บข้อมูลไว้ในอาเรย์ที่จองแบบพลวัต
(dynamic array) ด้วยตัวแปรสมาชิกสามตัว

- `T *mData` — อาเรย์ที่เก็บข้อมูลจริง
- `size_t mCap` — **ความจุ** คือจำนวนช่องที่จองไว้ใน `mData`
- `size_t mSize` — **ขนาด** คือจำนวนสมาชิกที่ใช้งานอยู่จริง

สมาชิกที่ใช้งานอยู่คือ `mData[0]` ถึง `mData[mSize - 1]` เสมอ ส่วนช่องที่
เหลือตั้งแต่ `mData[mSize]` ถึง `mData[mCap - 1]` เป็นที่ว่างที่จองไว้
ล่วงหน้าเพื่อให้การขยายในอนาคตถูกลง ช่องเหล่านั้น **ไม่ถือเป็นสมาชิกของ
เวกเตอร์**

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::fill(const T &value);
```

ที่ทำให้สมาชิกทุกตัวในเวกเตอร์มีค่าเท่ากับ `value` โดย

1. **ขนาดและความจุต้องไม่เปลี่ยน** ฟังก์ชันนี้แก้เฉพาะค่าของสมาชิกที่มีอยู่
   ไม่ใช่เพิ่มหรือลดจำนวนสมาชิก ดังนั้นห้ามแตะ `mSize` และ `mCap`
2. ถ้าเวกเตอร์ว่าง (`size() == 0`) ต้องไม่ทำอะไรเลย และต้องไม่เข้าถึง
   `mData[0]`
3. ใช้เวลา **O(n)** เมื่อ `n` คือขนาดของเวกเตอร์

## คำอธิบายฟังก์ชัน main

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ ไม่ใช่โปรแกรมที่ระบบ
ใช้ตรวจ โปรแกรมนี้อ่านจำนวนสมาชิก `n` กับค่า `value` แล้วอ่านสมาชิก `n` ตัว
ลงใน `CP::vector<int>` ที่สร้างด้วย `CP::vector<int> v(n)` จากนั้นพิมพ์

1. บรรทัดแรก: สมาชิกทั้งหมดก่อนเรียก `fill`
2. บรรทัดที่สอง: สมาชิกทั้งหมดหลังเรียก `v.fill(value)`
3. บรรทัดที่สาม: `v.size()` และ `v.capacity()` คั่นด้วยช่องว่าง เพื่อยืนยันว่า
   `fill` ไม่ได้เปลี่ยนขนาดหรือความจุ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

- อ่าน **ชุดคำสั่ง** และเรียก `fill` สลับกับ `resize`, `operator[]`,
  `clear`, `size` และการคัดลอกเวกเตอร์หลายครั้ง ไม่ใช่เรียก `fill` แค่ครั้ง
  เดียวตอนท้าย
- สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
- ตรวจค่าของสมาชิก **ทุกตัว** ด้วยค่าสรุป (digest) ที่ขึ้นกับทั้งค่าและลำดับ
  ดังนั้นการเติมค่าไม่ครบทุกช่อง หรือเติมเลยขอบเขตของ `mSize` จะถูกจับได้

## ตัวอย่าง

ตัวอย่างนี้ใช้กับ `main.cpp` ที่ให้ดาวน์โหลด

### ข้อมูลเข้า

```sample-input
5 7
1 2 3 4 5
```

### ข้อมูลออก

```sample-output
1 2 3 4 5
7 7 7 7 7
5 5
```

เวกเตอร์ที่สร้างด้วย `CP::vector<int> v(5)` มีทั้งขนาดและความจุเท่ากับ 5
หลังเรียก `v.fill(7)` สมาชิกทั้งห้าตัวจึงเป็น 7 ทั้งหมด ขณะที่ `size()` และ
`capacity()` ยังเป็น 5 เหมือนเดิม

## การทดสอบใน grader

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` ลงทุกช่อง |
| `2 x` | เรียก `fill(x)` |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4 i x` | กำหนด `v[i] = x` |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ด้วย copy constructor และ copy assignment แล้วพิมพ์ค่าสรุปของสำเนา โดยเวกเตอร์ต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |

คำสั่งที่รับดัชนี `i` จะถูกปรับด้วย `i % size()` ก่อนใช้งาน และถ้าเวกเตอร์
ว่างอยู่คำสั่ง `3` จะพิมพ์เครื่องหมาย `-` เมื่อจบคำสั่งทั้งหมดของบล็อกหนึ่ง
grader จะพิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

ขอบเขตของข้อมูล: แต่ละชุดทดสอบมีไม่เกิน 3 บล็อก แต่ละบล็อกมีสมาชิกไม่เกิน
1,000,000 ตัว สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน 10⁶ ชนิด `long long` ไม่
เกิน 2 × 10⁹ และชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน 5 ตัว
