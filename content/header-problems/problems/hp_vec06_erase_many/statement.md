# Vector Erase Many

ในโจทย์ก่อนหน้า การลบสมาชิกหนึ่งตัวออกจาก `CP::vector<T>` ต้องเลื่อนสมาชิก
ที่อยู่หลังตำแหน่งนั้นมาทางซ้ายหนึ่งช่อง ซึ่งใช้เวลา $O(n)$ ถ้าต้องลบ $k$
ตำแหน่งแล้วเรียกฟังก์ชันนั้นซ้ำ $k$ ครั้ง เวลารวมจะเป็น $O(k \times n)$
เพราะข้อมูลท้ายเวกเตอร์ถูกเลื่อนซ้ำ ๆ หลายรอบ ทั้งที่ความจริง
<b>สมาชิกแต่ละตัวควรขยับเพียงครั้งเดียว</b>

## คำอธิบาย :

งานของคุณคือเขียนฟังก์ชัน

```cpp
template <typename T>
void CP::vector<T>::erase_many(const std::vector<size_t> &positions);
```

ที่ลบสมาชิกทุกตำแหน่งที่อยู่ในรายการ `positions` ออกจากเวกเตอร์ในคราวเดียว
โดย

1. รายการ `positions` <b>เรียงจากน้อยไปมากอย่างเคร่งครัด</b> (ไม่มีค่าซ้ำ) และ
   ทุกค่าเป็นดัชนีที่ถูกต้อง คือน้อยกว่า `size()` เสมอ คุณไม่ต้องตรวจซ้ำ
2. ตำแหน่งทั้งหมดหมายถึงดัชนี <b>ก่อนการลบ</b> นั่นคือเทียบกับเวกเตอร์ตอนที่
   เรียกฟังก์ชัน ไม่ใช่ดัชนีที่เลื่อนไปแล้วระหว่างทาง
3. สมาชิกที่เหลือต้องเรียงตามลำดับเดิมและเริ่มที่ `mData[0]` ตามเดิม
   `size()` ลดลงเท่ากับจำนวนตำแหน่งที่ลบ และ `capacity()` ไม่เปลี่ยน
4. ถ้ารายการว่าง ต้องไม่ทำอะไรเลย
5. <b>ต้องใช้เวลา $O(n + k)$</b> คือเดินผ่านเวกเตอร์เพียงพาสเดียว และไม่ใช้
   หน่วยความจำเพิ่มตามขนาดข้อมูล แนวคิดคือใช้ดัชนีสองตัว ตัวหนึ่งสำหรับ
   "ตำแหน่งที่กำลังอ่าน" และอีกตัวสำหรับ "ตำแหน่งที่จะเขียนตัวถัดไป"

ไฟล์ `main.cpp` ของทั้งผู้ออกข้อสอบและของที่ให้ดาวน์โหลด `#include <vector>`
ไว้ก่อน `{{ds}}` แล้ว คุณจึงใช้ `std::vector<size_t>` ได้ทันทีโดยไม่ต้อง (และ
ไม่ได้รับอนุญาตให้) เพิ่ม `#include` ใน `{{submission}}`

## คำอธิบายฟังก์ชัน main :

ไฟล์ `main.cpp` ที่ให้ดาวน์โหลดเป็นโปรแกรมทดลองสั้น ๆ <b>ไม่ใช่</b> โปรแกรมที่
ระบบใช้ตรวจ โปรแกรมนี้อ่าน $n$ และสมาชิก $n$ ตัวลงใน `CP::vector<int>` จากนั้น
อ่าน $k$ กับตำแหน่ง $k$ ตำแหน่ง (เรียงจากน้อยไปมาก) ใส่ `std::vector<size_t>`
แล้วเรียก `erase_many` หนึ่งครั้ง และพิมพ์ `size()` ที่เหลือ ตามด้วยสมาชิกที่
เหลือทั้งหมดตามลำดับ

โปรแกรมที่ระบบใช้ตรวจเป็นโปรแกรมของผู้ออกข้อสอบ ซึ่งจะ

* อ่าน <b>ชุดคำสั่ง</b> และเรียก `erase_many` สลับกับ `resize`, `clear`,
  `operator[]` และการคัดลอกเวกเตอร์ ไม่ใช่เรียกครั้งเดียวตอนท้าย
* สร้างเวกเตอร์จากชนิดข้อมูลมากกว่าหนึ่งชนิด คือ `CP::vector<int>`,
  `CP::vector<std::string>` และ `CP::vector<long long>`
* <b>สร้างรายการตำแหน่งขึ้นเองภายในโปรแกรม</b> จากค่า seed หรือจาก
  (เริ่ม, ก้าว, จำนวน) ดังนั้นคำสั่งบรรทัดเดียวสั่งลบได้ถึงแสนตำแหน่ง รูปแบบ
  ที่ใช้มีทั้งการลบ <b>ช่วงติดกัน</b> (ก้าวละ $1$) และการลบ
  <b>กระจายทั่วเวกเตอร์</b>
* สั่งลบด้วยรายการว่าง และสั่งลบตำแหน่ง $0$ กับตำแหน่ง `size() - 1`
* คำนวณค่าสรุป (digest) ของสมาชิกทุกตัว การเก็บสมาชิกผิดตัวหรือเรียงผิดลำดับ
  จึงหลบไม่ได้

## Input :

ข้อมูลนำเข้าในหัวข้อนี้เป็นของ `main.cpp` ที่ให้ดาวน์โหลด<br>
บรรทัดแรก : รับจำนวนเต็ม $n$ แทนจำนวนสมาชิกของเวกเตอร์<br>
บรรทัดที่สอง : รับจำนวนเต็ม $n$ จำนวน คือ $a_1, a_2, \ldots, a_n$ แทนสมาชิก
ของเวกเตอร์<br>
บรรทัดที่สาม : รับจำนวนเต็ม $k$ แทนจำนวนตำแหน่งที่จะลบ<br>
บรรทัดที่สี่ : รับจำนวนเต็ม $k$ จำนวน คือตำแหน่ง $p_1 < p_2 < \cdots < p_k$
ที่จะลบ

## Output :

มีทั้งหมด $2$ บรรทัด โดย<br>
บรรทัดแรก : แสดง `size()` ที่เหลือ<br>
บรรทัดที่สอง : แสดงสมาชิกที่เหลือทั้งหมดตามลำดับ

## Examples :

### ตัวอย่างที่ 1

```sample-input
7
10 20 30 40 50 60 70
3
0 3 6
```

```sample-output
4
20 30 50 60
```

## คำอธิบายตัวอย่างที่ 1

ตำแหน่ง $0$, $3$ และ $6$ ของเวกเตอร์เดิมคือ $10$, $40$ และ $70$ เมื่อลบออก
ทั้งสามตัวจึงเหลือ $20, 30, 50, 60$ สังเกตว่าตำแหน่งทั้งสามเทียบกับเวกเตอร์เดิม
ถ้าตีความว่าเป็นตำแหน่งหลังการลบไปแล้ว คำตอบจะผิด

## การทดสอบใน grader :

ข้อมูลเข้าของ grader เป็นชุดคำสั่ง ประกอบด้วยหลายบล็อก แต่ละบล็อกเริ่มจาก
เวกเตอร์ว่างและระบุชนิดข้อมูลของตัวเอง ภายในบล็อกจะมีคำสั่งผสมกันดังนี้

| คำสั่ง | ความหมาย |
|---|---|
| `1 n seed` | ปรับขนาดเป็น `n` แล้วเติมข้อมูลที่สุ่มจาก `seed` |
| `2 k seed` | สร้างรายการตำแหน่งแบบกระจายประมาณ `k` ตำแหน่ง แล้วเรียก `erase_many` |
| `3 i` | พิมพ์สมาชิกตำแหน่งที่ `i` |
| `4 start stride count` | สร้างรายการ `start`, `start+stride`, … จำนวน `count` ตำแหน่ง แล้วเรียก `erase_many` |
| `5 n` | เรียก `resize(n)` แล้วพิมพ์ขนาดใหม่ |
| `6` | เรียก `clear()` แล้วพิมพ์ขนาดกับผลของ `empty()` |
| `7` | คัดลอกเวกเตอร์ แล้วลบหัวกับท้ายของสำเนา โดยต้นฉบับต้องไม่เปลี่ยน |
| `8` | พิมพ์ขนาดและค่าสรุปของสมาชิกทั้งหมด |
| `9` | พิมพ์สมาชิกทุกตัวในบรรทัดเดียว (ใช้เฉพาะชุดทดสอบเล็ก) |
| `10` | เรียก `erase_many` ด้วยรายการว่าง (ต้องไม่เปลี่ยนอะไร) |

คำสั่ง `2` และ `4` จะพิมพ์จำนวนตำแหน่งที่สร้างได้จริงพร้อมขนาดใหม่ รายการ
ตำแหน่งที่สร้างขึ้นถูกตัดให้อยู่ในช่วงที่ถูกต้องเสมอ เมื่อจบบล็อก grader จะ
พิมพ์ขนาดและค่าสรุปสุดท้ายของบล็อกนั้น

## Constraints :

* แต่ละชุดทดสอบมีไม่เกิน $3$ บล็อก
* แต่ละบล็อกมีสมาชิกไม่เกิน $1{,}000{,}000$ ตัว
* ลบได้ครั้งละไม่เกิน $100{,}000$ ตำแหน่ง
* สมาชิกชนิด `int` มีค่าสัมบูรณ์ไม่เกิน $10^6$
* สมาชิกชนิด `long long` มีค่าสัมบูรณ์ไม่เกิน $2 \times 10^9$
* สมาชิกชนิดข้อความเป็นตัวอักษรภาษาอังกฤษตัวเล็กยาวไม่เกิน $5$ ตัว
